# ラスト・ツー

ババ抜きの「最後の2人」だけを遊ぶ、表情の読み合いゲームの試作です。

遊ぶ: https://kudo12711-boop.github.io/last-two/

- CPU（ポン太・ミケ・クロ）と1対1で対戦します。
- 「カメラで表情を映す」を押すと、あなたの表情をキャラクターがまねします。映像は端末の中だけで使い、どこにも送りません。
- スマホでも、上のURLを開けばカメラが使えます。

## キャンピングカー世界一周（放置型の旅）

遊ぶ: https://kudo12711-boop.github.io/last-two/camper/

- アプリを閉じているあいだもキャンピングカーが走り、次に開くと進んだ場所の車窓の景色が見られます。
- 景色はその場所のいまの時刻・天気・気温に合わせて変わります（天気は Open-Meteo、地名は BigDataCloud から取得）。
- 作り方: `/mnt/project-files/camper/tools/` の部品を `python3 build.py camper/index.html` でつなげています。

## ゆびで めいろ（幼児向け）

遊ぶ: https://kudo12711-boop.github.io/last-two/meiro/

- キャラクターを指でなぞって、ゴールまで連れていく迷路です。かべは通りぬけられず、ぶつかると「ぽよん」と止まるだけです。
- むずかしさは ★〜★★★★（2さい〜5さい向け）。毎回ちがう迷路が自動でできます。
- 声は Kokoro-82M（Apache-2.0）で作った音声を `meiro/voice/` に入れています。作り方は `/mnt/project-files/meiro/tools/`。

## すうじで てんつなぎ（幼児向け）

遊ぶ: https://kudo12711-boop.github.io/last-two/tentsunagi/

- 番号の順に点を指でつなぐと絵ができあがり、色がついて動き出します。点の数は3〜30こ、1・2・3／2・4・6／あいうえお／ABC の順でも遊べます。
- おうちの人が描いた形や、写真・紙の絵のりんかくから、オリジナルの点つなぎを作れます。
- 声は Kokoro-82M（Apache-2.0）で作った音声を `tentsunagi/voice/` に入れています。作り方は `/mnt/project-files/tentsunagi/tools/`。

## ぬけぬけリング（1人用の連鎖パズル）

遊ぶ: https://kudo12711-boop.github.io/last-two/nukenuke-ring/

- 輪になった5つの手札から1枚を隣へ渡すと、ペアが消えて、消えた手札がまた次へ1枚渡し…と連鎖します。
- 10ワールド100面と、手数ぴったりで全部消す「つめぬけ」50問、毎日変わる「今日のステージ」。
- ヒント・もどす券・月額パス・広告はすべて仮のもので、本物のお金は動きません。
