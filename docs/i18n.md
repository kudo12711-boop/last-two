## これから

- 都道府県パズルの方針を決める。
- アプリにするとき: ストアの説明文・スクリーンショットを英語でも用意、プライバシーポリシー。
- ほかの言語（中国語・韓国語・スペイン語など）は、どのゲームも `TEXT` に1つ足し、声を作れば ふやせる。

## 技術メモ

- 言語の決め方（どのゲームも同じ）: URL の `?lang=ja|en` → そのゲームで前回えらんだもの → 入口ページで えらんだもの（localStorage `games-lang`）→ ブラウザの言語（日本語以外は英語）。
- 声の設定は `ai:1`〜`ai:4`（AIのこえ 何番）。日本語は `jf_alpha / jf_gongitsune / jf_nezumi / jf_tebukuro`、英語は `af_heart / af_bella / bf_emma / am_michael` の フォルダ。おうこく だけは `voice/en/<キー>.mp3`。
- 英語の声の作り方: `/mnt/project-files/i18n/tools/en_voice.py`。Kokoro-82M v1.0（onnx、`kokoro-v1.0.onnx` と `voices-v1.0.bin` は github.com/thewh1teagle/kokoro-onnx の releases）を venv（`pip install kokoro-onnx soundfile lameenc`）で動かす。英語は espeak で読むので、日本語のときのような 聞き取りで選ぶ作業は いらない。セリフの一覧は、ゲームのページを `?lang=en` で開いて `TEXT.en.say` などから取り出す。
- huggingface.co は この作業場所から つながらない（whisper で聞き取りの確認は できなかった）。
