## 公開の方針（2026-11-16 くどうさん決定）

LINE でつながっている人に試してもらうため、「かくしURL」で公開する。くどうさん「１でお願いします。今後この開発の公開はこの方針でお願いします。」

- 推測できない長い名前のフォルダ（`try-` ＋ ランダムな英数字）に置く。
- 入口ページ「あそびのいりぐち」（`games/`）や他のページからはリンクしない。→ **2026-11-25 くどうさん「入り口のページに載せても隠し URL のやつは隠し URL のまんま入り口に載せられるようにしてください。」→ かくしURL のまま 入口ページ（games/）に「🧪 ためし版」の札つきで のせた。ゲームのページの 検索よけ（noindex）と フォルダ名は そのまま。**（英語の入口からは `?course=abcen` で ABC English コースが開く）
- 検索エンジンに載らないよう `<meta name="robots" content="noindex,nofollow">` を入れる。
- 試してもらった後は、フォルダを消せば見られなくなる。
- 注意: リポジトリ自体は公開なので、GitHub でファイル一覧を見ればフォルダ名は分かる。URL を知らない人が偶然見つけることはまずない、という程度の「かくし」。
- このゲームの開発中は、新しい版もこの方針で公開する（正式公開のときに、いりぐちへの追加をくどうさんと相談する）。

## 技術メモ

- ファイル: `try-c73775bbf6bb9c41/index.html`（1ファイル）＋ `voice/<声>/<key>.mp3`。`../common/kakin.js` を読む（game: `hiragana`）。コピーは `/mnt/project-files/hiragana/`。
- コース: `COURSES`（hira = ui ja・scr ja / abcja = ui ja・scr en / abcen = ui en・scr en、game は kakin の id: hiragana / abc）。UI の文字は `TEXT[ui]`（abcja は `TEXT.abcja`）、字・どうぶつ・かぞく・よみふだ は `[scr]`。声は `keyLang(key)`: 文字（k#/a#）・an_・f_・y# は scr の声、ほかは ui の声。abcja の 日本語の いみは `JA_MEAN`。
- 記録: localStorage `hiragana-v1`（course, voice, snd, name / got（字ごとの正解数）/ zukan / unlock（①で出す字の数）は どれも コースごと）。v0.1 の ja / en は hira / abcen に うつす。
- 声のしくみ: `say(...keys)` は Promise のくさり（chain）に つないで順番に読む。`hush()` は「もどる」・画面を閉じたとき だけ（gen を進めて、待っている声を捨てる）。`run` は遊びを始める／やめるたびに増え、古いタイマーを無視する。
- 字の順番は `SCRIPT[lang].order`、似ている字は `similar`。① は order の先頭 `unlock` 文字から、正解の少ない字ほど出やすく選ぶ。
- 声: 1文字（`k0`〜`k45`＝あ〜ん、`a0`〜`a25`＝A〜Z）は てんつなぎ の声をコピー。それ以外のセリフは `LINES`（index.html の `//@@LINES-BEGIN`〜`END`）から `/mnt/project-files/hiragana/tools/make_voice.py` で作る（Kokoro-82M v1.0 onnx、日本語は misaki の G2P。助詞の「は」は わ に直す）。セリフを取り出す: index.html の data〜LINES-END を node で評価して JSON に（`tools/lines.json`）。huggingface は つながらないので、聞き取りでの選びなおしは していない。
- ④「ロボと」: よみふだを読み終えてから 1.2秒後に、ロボの手が 6.5〜9秒かけて正解の札へ動く。

- アプリの準備（2026-11-19）: `manifest.webmanifest`（アプリの名札）、`app/` の仮アイコン、`app-files.json`（アプリとして開いたときに まとめて保存するファイルの一覧）、`<head>` に `common/app.js`（オフライン）と `common/hikkoshi.js`（games.hajimaruyo.com への記録の引っ越し）。ファイルを足したり変えたりしたら `node tools/make_app.cjs --no-icons` で一覧を作りなおす。くわしくは [app-plan.md](app-plan.md)。
- 日本語の声（2026-11-23〜）: VOICEVOX。台本は `/mnt/project-files/voice-ja/build_lines.py`（`H`）、作るのは `make_voicevox.py hiragana`。フォルダは `voice/vv_himari|vv_metan|vv_zunda|vv_hau/`（前の Kokoro の jf_* は消した）。この前の make_voice.py（Kokoro）は 英語の声にだけ使う。[voice-ja.md](voice-ja.md)
