## v0.1 の中身

ホームに大きなボタンが3つ（⛄ つくる／📖 ずかん／🌙 よるの ダンス）。

1. **ころがす**（上から見た 雪の はらっぱ）
   - 画面を指でなぞると、雪の玉が指のほうへ転がる。転がった あとは 雪が なくなって 草が 見え、しばらくすると 雪が また積もる。雪の ある ところを 転がすほど 大きくなる（雪が少ないと 少ししか 大きくならず、声で「雪が たくさん あるところを…」と教える）。
   - 上の「おおきさ」の ものさしに ⭐ の しるし。⭐ をこえると「✔ これで いい！」が出る。いちばん大きくなると 自動で次へ。
   - からだ → あたま の順に 2つ作る。あたまは からだより 小さくなるように 上限がある。作った からだは はらっぱに のこり、あたまは ぶつかると よける。
   - 7びょう さわらないと 👆 が 出て「画面を 指で なぞってみてね」。
2. **かさねる**（横から見た 昼の 雪げしき）
   - からだの上に 点線の まる。あたまを 指で 持っていって のせる。あたまを タッチするだけでも ぴょんと のる（小さい子むけ）。ずれた ところで はなすと 雪の上に もどる。
3. **かざる**
   - 下に「め・はな・くち・ほっぺ・ぼうし・マフラー・うで・ボタン・いろ」の タブ。えらぶと つく。もう一度 えらぶと はずれる。ついた ものは 指で 動かせる（ふくわらい みたいに 好きな 場所へ）。雪だるまの 外へ 出すと はずれる。
   - 「↩ もどす」「🎲 おまかせ」（ぜんぶ ランダムに つける）「⭐ できた！」。
4. **できあがり**: ずかんに 番号つきで しまう（◯ごう）。タッチすると 手を ふって ジャンプ。
5. **ゆきだるま ずかん**: 作った 雪だるまが 新しい じゅんに 並ぶ。えらぶと 大きく 見られて、そこから その子を まんなかにして ダンスへ。けす（2かい おす）。
6. **よるの ダンス**: 夜空・月・星・雪の中で、ずかんの 雪だるま（多いときは 新しい 8人、2れつ）が 音楽に あわせて おどる（ぴょんぴょん・ゆらゆら・手ふり・ジャンプ・くるくる・首ふり、2小節ごとに かわる）。タッチすると 大ジャンプして くるっと 回る。まだ 1人も いないときは おてほんの 2人が おどる。🎵 で 音楽 オン／オフ。

## 技術メモ

- ファイル: `try-6c7ad175ab6aa707/index.html`（1ファイル、canvas に描く）＋ `voice/<声>/<key>.mp3`。`../common/kakin.js` を読む。コピーは `/mnt/project-files/yukidama/`。
- 雪だるまの持ち方: `{rb, rh, col, parts:[{k, v, x, y}]}`。rb・rh は からだ・あたまの 半径（はらっぱの みじかい辺の 20% が 1）。あたまに つくもの（め・はな・くち・ほっぺ・ぼうし）は あたまの 半径を 1 として あたまの 中心から、ほかは からだの 半径で からだの 中心から。め・ほっぺ・うで は 右がわだけ 持って 左は かがみうつし。
- 描くのは `drawMan(ctx, m, x, 地面のy, U, pose)`。pose で 上下・かたむき・回転（yaw＝たての軸まわりの角度。玉は まるいまま、かざりの 横の位置を 球の上の 角度として 回し、うらへ 回ったら かくす。うでは 手前なら からだの あと、おくなら からだの まえに 描く）・つぶれ・あたまの ずれ・うでの 角度・まばたき・うしろむき を かえられる（ダンスも ずかんも 同じ 関数）。
- ころがす: はらっぱを 22px の マスに 分けて 雪の量（0〜1）を もつ。転がると へり、1びょうに 0.06 ずつ もどる。大きさは 半径² が「動いた きょり × 雪の量（さいていでも 0.3）」に 比例して ふえる（からだの いちばん大きい ところまで、はらっぱの 幅 の 10ばいくらい 転がす）。雪の玉の もようは 球の上の点を 進む向きに 回して 描く。
- 音楽: WebAudio で その場で 鳴らす オリジナルの 4小節（C・Am・F・G、112 BPM）。ダンスの 動きは 音楽の 拍に あわせる。
- 記録: localStorage `yukidama-v1`（lang, voice, snd, music, men＝ずかん, no＝次の番号）。
- テスト用: `?test=1` で `window.__yuki` が使える。
- 声: 日本語は VOICEVOX（台本 `/mnt/project-files/voice-ja/build_lines.py` の `G['yukidama']`、作るのは `make_voicevox.py yukidama <リポジトリ>/try-6c7ad175ab6aa707/voice`）。英語は Kokoro（`/mnt/project-files/yukidama/tools/make_voice.py`、台本は index.html の `//@@LINES-BEGIN`〜`END` を node で JSON にしたもの `lines.json`）。[voice-ja.md](voice-ja.md)
- アプリの準備: `tools/apps.json` に 追加済み。ファイルを変えたら `node tools/make_app.cjs --no-icons` で `app-files.json` を作りなおす。
