# てんつなぎ（幼児向け）

最終更新: 2026-11-11 ／ いまの版: v0.2（公開済み）。はじめの名前は「すうじで てんつなぎ」

## ひとことで

番号のついた点を、順番に指でつないでいくと絵ができあがる「点つなぎ」です。全部つなぐと絵に色がついて動き出し、鳴き声や音が出ます。

## 遊ぶ場所

- 公開ページ: https://kudo12711-boop.github.io/last-two/tentsunagi/ （ログインなしで誰でも遊べます。2026-10-26 公開）
- ファイル: `/mnt/project-files/tentsunagi/index.html`（声は `voice/`）

## 生まれたきっかけ

2026-10-25、くどうさん「絵の一部が点々になっていて、点々に番号がついていて、番号の順番に線でつないでいくと全体の絵が完成するゲーム。数字は20ぐらいまでで、レベルに合わせて増減できるように」。

続けて、Claude からの提案（完成すると動いて鳴く、次の数字が光って声で数える、2とび・あいうえお・ABC、おうちの人の絵や写真から作る、シール帳）に、くどうさん「全部入れてください」。

## 遊び方（いまの版）

- 「はじめる」で、まだ作っていない絵が出てくる。点が25こ以上なら むずかしい絵、12こ以下なら かんたんな絵を先に出す。シールちょうの「？」を押して選んでもよい。
- 光っている点から次の点へ指でなぞると線がつながる。点をタップするだけでもつながる（設定で「なぞるだけ」にもできる）。
- つなぐたびに声で「いち、に、さん…」と読みあげ。半分で「そのちょうし！」、最後は「あと ひとつ！」。絵がぐるっと一周するときは「さいごは はじめの てんに もどろう！」。
- 全部つなぐと、まっすぐな線が本当の形にすーっと変わり、色・顔などがついて動き出す。鳴き声や音（ねこ「にゃーん」、くるま「ぶっぶー」で走り去る、ロケットは発射、くじらは潮ふき など）と「○○が できたね！」。
- 絵は31まい: ほし、ハート、さかな、おうち、りんご、ねこ、ロケット、ヨット、きのこ、くじら、ちょうちょ、うさぎ、くるま、チューリップ、かさ、ゆきだるま、ふうせん、アイスクリーム、くま、ぶた、ひよこ、ひこうき、イルカ（v0.2 で追加）。かどの多い むずかしい絵: かめ、おしろ、きょうりゅう、タコ、おうかん、クリスマスツリー、きしゃ、ぞう（v0.2 で追加。おしろは かどが36こあり、点を37こ以上にすると全部が点になる）。
- むずかしさ: ★5こ（2さい〜）、★★10こ、★★★15こ、★★★★20こ、★5 30こ（6さい〜）、むずかしい 45こ（7さい〜）。−／＋で3〜60こまで変えられる（ABCは26、あいうえおは46まで）。点が30こをこえると、点と数字を少し小さくする。点が14こより少ないときは、絵の残りがはじめから描いてある（絵の一部だけが点々）。
- かぞえかた: 1・2・3／2・4・6（2とび、60まで）／あ・い・う（あ〜ん）／A・B・C（Zまで）。
- じぶんで つくる: おうちの人が指で形を描く、または紙に描いた絵や写真を選ぶと、りんかくを自動で見つけて点つなぎにする（「こさ」と「はんてん」で調整、色も選べる）。写真から作ったものは、完成すると中に写真が出てくる。最大8こ保存、設定画面から消せる。
- こえを ろくおん: おうちの人が自分の声で 1〜60、2〜60（2とび）、あ〜ん、A〜Z、ほめことばや「○○が できたね」を録音でき、録音したものは AI の声のかわりに使われる。録音はその端末の中だけに保存。ますを選んで録音すると次のますに進むので、続けて録りやすい。
- できた絵はシールちょうに色つきで並び、2回目からは「×2」と回数が出る。

## 技術メモ

- リポジトリ `tentsunagi/index.html`（1ファイル）＋ `tentsunagi/voice/<声>/<key>.mp3`。key: `n1`〜`n60`、`k0`〜`k45`（あ〜ん。「を」は「お」と読む）、`a0`〜`a25`（エー〜ゼット）、`start0/1` `here0/1` `cheer0/1` `last0` `close0` `praise0/1`、絵ごとに `done_<id>`（○○が できたね）と `cry_<id>`（鳴き声）。声はそのパズルで使う分だけ読みこむ。
- 絵は 0〜100 のます目に、まっすぐ（l）とカーブ（c, q）、円や だ円の一部（a, e。角度は度で、ふえる向きが時計まわり）でりんかくを1本の閉じた線として書いてある（`PICS` の `path()`）。かど（32度以上曲がる所）は必ず点にし、残りの点は長い区間から順に配る。点が `FULL_N`=14 より少ないときは、はじめの点から一部分だけを点にして残りは描いておく。
- 完成アニメ: 点と点を結ぶまっすぐな線から本当の形へ形を変え（`morphPts`）、色 → `back`/`art`/`front`（細かい絵）→ `anim(t)`（動き）。
- 番号の位置は、りんかくの外向きを基本に、ほかの点や番号と重ならない向きを選ぶ（`labelSpots`）。
- じぶんで つくる: 指描きは線をまびき（RDP）→ 角を丸め（チャイキン法）。写真は160pxに縮めて白黒にし、しきい値（大津の方法）→ すきまを少し太らせ → いちばん大きいかたまりのまわりをなぞる（ムーア近傍）。ふちの明るさで、どちらが「もの」かを自動で決める。
- 録音: MediaRecorder で最長3秒、IndexedDB `tentsunagi`（ストア `voice`、キーは声ファイルと同じ key）。再生前に前後の無音を切る（`decodeRec`）。録音があれば AI の声より優先（`say`）。
- 保存（localStorage）: `tentsu-book`（絵ごとの回数）、`tentsu-custom`（作った絵、写真は360pxのJPEG）、`tentsu-n` `tentsu-mode` `tentsu-guide` `tentsu-touch` `tentsu-voice` `tentsu-sound`。
- 声の作り方は [ゆびで めいろ](meiro.md) と同じ（Kokoro fp16 で候補を作り、whisper-tiny で聞き取って一番合うものを選ぶ）。数字やアルファベットで聞き取られたときは読みに直してから比べる。1文字の読み（あ・に など）は whisper-tiny が聞きまちがえやすいので、最初の音が合っているものを優先し、合わなかった約130こは話し方を変えて作り直した（cand2.py）。それでも「にゃーん」などは AI が苦手なので、気になるときは録音で差しかえてもらう。v0.2 の追加分は slots3.py / cand3.py / pick3.py。道具は `/mnt/project-files/tentsunagi/tools/`（slots.py＝セリフ一覧, cand.py, asr.mjs, pick.py）。
- むずかしい絵には `hard: true`。`nextPic` が点の数に合わせて選ぶ。
- 課金: `<script src="../common/kakin.js">` を ゲームの script の前に読み、`Kakin.setup({game: 'tentsunagi', ...})`。🔒は `.kk-lock` クラス、さわったら `Kakin.ask()`、ぜんぶ版かどうかは `Kakin.full()`。むりょうの範囲は `FREE_PICS` `FREE_MODES` `FREE_CUSTOM`。「はじめる」（nextPic）は 遊べる絵の中から えらぶ。前に作った絵は ぜんぶ遊べるまま。
