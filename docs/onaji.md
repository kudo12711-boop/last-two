## 遊びかた（v0.1）

ホームで 遊びを えらぶ:

- 🟢 **おなじ を さがそう**: 上に「おてほん」の絵。下の候補から、おてほんと まったく同じ絵を1つ えらぶ。
- 🟠 **ちがう を さがそう**: 候補は1つをのぞいて おてほんと同じ。1つだけ ちがう絵を えらぶ。
- 🟣 **うごき を みてね**: 絵は ぜんぶ同じで、うごきかた（はねる・まわる・ふくらむ・ゆれる・ふるえる・くるっと うらがえる・とまっている）だけが ちがう。「おなじ うごき」と「ちがう うごき」が交互に出る。

- 1回の あそびは 5問。5問できると シールが1まい もらえて「シールちょう」（36しゅるい）に たまる。
- まちがえると、その候補に 大きな ✕ が出て うすくなり、「色が ちがうね」「数が ちがうね」などと声で教える（「ちがう」の遊びで おなじ絵をさわると「これは お手本と同じだね」）。2回まちがえると、まちがいの候補を1つ 自動で消す（💡ボタンでも消せる）。🔊 で問題をもう一度 読む。
- 正解のあとは、選ばなかった候補を うすくするだけ（赤まるは 出さない。v0.1 では出していたが、くどうさんの声で やめた）。「ちがう」の遊びでは、選んだ正解の絵の ちがう ところに 赤まる。
- **赤まる（○）は 正解の絵にだけ出す。** 日本では ○ が「せいかい」の しるしなので、まちがいの絵に ○ を出すと「これが正解」に見えてしまう（v0.3 まで「おなじ」「うごき（おなじ）」で まちがえた絵に赤まるを出していた）。まちがえた絵には 大きな ✕ を出して うすくし、どこが ちがうかは声（「色が違うね」など）で教える。

## 技術メモ

- ファイル: `try-cb0575cc80344ed4/index.html`（1ファイル）＋ `voice/<声>/<key>.mp3`。`../common/kakin.js` を読む（game: `onaji`）。保存は localStorage `onaji-v1`（lang, voice, snd, theme, lv, stickers, rounds）。
- 絵: `THEMES` の各テーマが `params`（ちがえられる ところ）と `draw(p)`（SVG を文字で返す、100×100）を持つ。param は `vals`（とりうる値）・`lv`（どの★で ちがえるか）・`cat`（声で言う ちがいの種類 Kind/Color/Count/Shape/Part/Face）・`at(p, base)`（赤まるの [x, y, 半径]）。
- 問題づくり: `mutate(th, base, lv)` が ★なら2か所、★★・★★★なら1か所を変える。描いた SVG の文字が おてほんと同じになる変え方（たとえば 1すくいのアイスの 2すくいめの色）は使わない。候補どうしも SVG の文字で重なりを さける。
- うごき: CSS アニメ（`.mv-jump` など、時間は `--d`）。`{t: 種類, sp: 'mid'|'fast'|'slow', rev: 逆まわり}`。★と★★は種類のちがい、★★★は はやさ・向き・にている種類。
- 画面の大きさ: `layout()` が画面の縦横から、おてほんと候補の大きさ・列の数を毎回計算する（横長の画面では おてほんが左）。
- 声: hiragana と同じ「順番待ち」（`say` は Promise のくさり、`hush` は もどる・画面を閉じたときだけ）。セリフは index.html の `//@@LINES-BEGIN`〜`END`。日本語は漢字まじりで書き、助詞の「は」は「わ」と書く。作り方: LINES を node で取り出して `/mnt/project-files/onaji/tools/lines.json` にし、`KOKORO_DIR=<モデル> python /mnt/project-files/onaji/tools/make_voice.py lines.json voice`（Kokoro-82M v1.0 onnx、モデルは github.com/thewh1teagle/kokoro-onnx の releases、venv に `pip install kokoro-onnx soundfile lameenc "misaki[ja]"`）。
- アプリの準備: `tools/apps.json` に登録済み。ファイルを変えたら `node tools/make_app.cjs --no-icons` で `app-files.json` を作りなおす。
- 動作確認（2026-11-23）: 6テーマ×★3段階×3つの遊び で 各300問を作り、「正解が1つだけ」「候補の数が正しい」ことを確認。スマホ縦（390×780）とタブレット横（1024×700）の画面で、正解・まちがい・シール画面を確認。
