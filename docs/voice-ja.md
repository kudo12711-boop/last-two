# 日本語の読み上げ（AI の声）の作り方と きまり

最終更新: 2026-11-23

## いきさつ

- **2026-11-23**（PR #157、くどうさん「公開して」で公開）くどうさん「全てのゲームで日本語が不自然なところが結構たくさんあるので、可能な限り直してください。自然な日本語の発音になるようにしてください。特に数字の読み上げはひどいです。」
- 原因は 3つありました。
  1. それまでの AI の声（Kokoro-82M）は、日本語の **アクセント（高い・低い）を学んでいない** ため、「に」「ご」のような短いことばや数字が とくに くずれる。
  2. 台本を ひらがな・ことばごとに「、」で区切って書いていたので（例「ひかってる、みちを、すすんでね。」）、声が **ぶつぎり** になっていた。
  3. ひらがなだけだと 読みを まちがえる（「はち」が 助詞の「は」＋「ち」→「わち」、「花の上」が「はなのじょう」など）。
- くどうさん「有料サービスに使ってもいいかどうかを確認した方が良ければした上で、使ってください。私は使うことには賛成です。」→ 日本語の声を **VOICEVOX** で 全部 作りなおした（英語の声は Kokoro のまま）。

聞きくらべの見本（前の声と新しい声）: https://claude.ai/artifact/FwoLnrZ4phiDXPEYUzJnPq （くどうさんが claude.ai にログインしたときだけ開ける）

各ゲームの「おうちのかたへ」「せってい」などの 声の説明に 書いてある（めいろ・てんつなぎ・まちがいさがし・ひらがな あそび は 声の説明文、おなじ？ちがう？・あみだくじ・ゆきだま・ボールなげ は「おうちのかたへ」の説明、かくれんぼ・けずって は 声の設定の下、ふくわらい は 説明の画面、おうこく は せってい の画面）。ストアの説明文（/mnt/project-files/app/store-listing.md）にも 書くこと。

## 台本の きまり（作りなおすときも 守る）

- 台本は `/mnt/project-files/voice-ja/build_lines.py` に まとめてある（`python build_lines.py` → `lines/<ゲーム>.json`）。画面の ひらがな の文とは 別。
- 「、」は 息つぎする ところだけ。ことばの区切りは 半角スペース（声には 入らない）。
- 読みや アクセントが まよう ことばは 漢字で書く（蜂・木・植木鉢・花の うえ・蜂蜜 など）。
- 数字・1もじの かな・一部の 鳴き声は「@」ではじまる **アクセントつきカナ**（例 `@ニジュウサ'ン`、`'` の前の音が高く そのあと下がる）で 1つずつ 指定する。ふつうの文で わたすと「はち」→「わ ち」、「は」→「わ」、「へ」→「え」と 読まれてしまう。
- 子どもに 数える 言い方: いち・に・さん・よん・ご・ろく・なな・はち・きゅう・じゅう。かくれんぼの かぞえうたは イーチ・ニーイ・サーン・シーイ・ゴー。
- どう読まれるかは、VOICEVOX の `/audio_query` の `kana` で 確かめられる（`'` の位置が アクセント）。

## 作り方（技術メモ）

1. VOICEVOX エンジン（https://github.com/VOICEVOX/voicevox_engine の releases、`voicevox_engine-linux-cpu-x64-<版>.7z.001`、2026-11-23 は 0.25.0）を ほどいて `./run --host 127.0.0.1 --port 50021`。
2. venv に `lameenc numpy soundfile`。
3. `python /mnt/project-files/voice-ja/make_voicevox.py <ゲーム> <リポジトリ>/<フォルダ>/voice [key,key,...]`
   - ふつうの ゲーム → `voice/vv_himari|vv_metan|vv_zunda|vv_hau/<key>.mp3`（AIのこえ 1〜4。コードの `AI_VOICES.ja`）
   - おうこく → `oukoku/voice/ja/<key>.mp3`（役ごとの声は make_voicevox.py の OUKOKU）
   - 速さ 0.95、抑揚 1.25、mp3 48kbps モノラル。
4. 声のフォルダ名を かえたのは、ブラウザや オフライン保存（sw.js）に のこった 古い声が 出ないようにするため。前の Kokoro の声（jf_*）は 消した（git の履歴には のこる）。
5. 保存してあった設定 'ai:jf_alpha' などは 今までどおり AIのこえ 1〜4 として 読める。
6. 声を足したら `node tools/make_app.cjs --no-icons` で app-files.json を 作りなおす。

## 対象のゲーム

めいろ・まちがいさがし・ふくわらい・かくれんぼ・けずって・てんつなぎ・おうこく・ひらがな あそび・おなじ？ ちがう？・どうぶつ あみだくじ・ころころ ゆきだま・ぽーん！ ボールなげ（最後の5つは かくしURL）。
都道府県パズル は AI の声が なく 端末の読み上げなので、県の名前を 漢字で 読ませるように かえた（ひらがなだと アクセントが くずれやすい）。
キャンピングカー は 🔊 を押したときだけ 端末の読み上げ（今回は さわっていない）。
ぬけぬけリング・ラスト・ツー・いきもの ずかん は 声なし。
これから作る ゲームも、日本語の声は この作り方に そろえる。
