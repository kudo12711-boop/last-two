# もういいかい？ かくれんぼ（幼児向け）

最終更新: 2026-11-11 ／ いまの版: v0.2（公開済み）

## ひとことで

小さな子ども向けのかくれんぼです。かくれた どうぶつを さがす、おうちの部屋の写真の中で さがす、自分が かくれて おにさんに さがしてもらう、の3つの遊び方があります。

- ファイル: `/mnt/project-files/kakurenbo/index.html`

## 生まれたきっかけ

2026-11-03、くどうさん「子ども向けのかくれんぼゲームを考えたいです」。Claude が3つの案を出しました。

- A. もりの かくれんぼ: 木や箱のうしろに どうぶつが かくれ、耳やしっぽが少し見えている。
- B. おうちで かくれんぼ: 自分の部屋の写真の中に、家族の顔やどうぶつが かくれる。声は家族の録音。
- C. こんどは きみが かくれる番: 子どもが かくれる場所を選び、おにさんが さがしにくる。

くどうさんが「A+B+C ぜんぶ入り」を選びました。まちがいさがし（ちがいを見つける）や、同じころに作っているスクラッチ・福笑いと遊びがかぶらないよう、「どこかな？とさがす」「みつけた！」と「かくれる側のドキドキ」を中心にしています。

## 遊び方（いまの版）

- **みんなを さがそう**（A）: もり・おうち・うみ・ゆきやま から選ぶ。どうぶつたちが並んで あいさつ → 画面が「めを つぶって かぞえよう」になり 1〜5 を数える → 子どもが「もういいかい？」ボタンを押す。ときどき「まあだだよ！」と返ってきて、もう少し数える → 「もういいよー！」で さがす。
  - かくれる数は 1ぴき（2さい〜）・3びき（3さい〜）・5ひき（4さい〜）。小さい子ほど よく見えている。
  - ちがう所をさわると ゆれて、ときどき ちょうちょや てんとうむしが飛び出す（はずれも楽しい）。
  - しばらく見つからないと、かくれている子が「くすくす」と少し顔を出す。💡 でも教えてくれる。
  - 見つけた子は上の列に飛んでいき、全部見つけると紙ふぶき。
  - 「なかよし ずかん」に集まる（36しゅるい。まだの子はかげだけ見える）。ときどき「ひみつの おともだち」（ユニコーン、きょうりゅう、おばけ など）も かくれている。
- **おうちで かくれんぼ**（B）: 部屋の写真をとる（または選ぶ）と、その写真の中に かくれる。写真の一部を上にかぶせるので、ソファや家具のうしろから顔を出しているように見える。
  - おうちのかたが「かくれる場所」をタップで選べる（選ばなくても自動で決まる）。部屋の写真と場所は保存され、次からはすぐ遊べる。
  - 家族の顔を入れると（カメラか写真から、まるく切りぬく）、家族も かくれる。顔は A や C でも出てくる。
- **きみが かくれる番**（C）: 自分（どうぶつ か 家族の顔）と おにさん（くま・ライオン・さる・ぞう か 家族の顔）を選ぶ → かくれる場所をタップ → おにさんが数えて「もういいかい？」→ 子どもが「まあだだよ」か「もういいよ！」を押す → おにさんが「ここかなあ？」「いないなあ」と さがしてまわる。近づくと「ドキドキ」。
  - 見つかったら「みーつけた！」。見つからなければ「まいった！どこにいたの？」→ 子どもが自分の場所をタップして「ここだよー！」、メダル🏅がもらえる。
- **声**: AI の声（4種類）。おうちのかたが「もういいよー！」「まあだだよ！」「みーつけた！」「ここじゃないね」「ぜんぶ みつけたね！」「ここだよー！」を録音すると、その場面は録音が流れる。
- 日本語と英語を切りかえられる（英語の声はスマホの読み上げ）。
- 写真・顔・録音は端末の中だけに保存し、外へは送りません。

## 技術メモ

- リポジトリ `kakurenbo/index.html`（1ファイル）＋ `kakurenbo/voice/<声>/<場面><番号>.mp3`。場面: intro0-1, num0-4, ask0, mada0, ready0, seek0-1, room0, found0-2, miss0-2, hint0-1, clear0-1, rare0, hide0, koko0-1, inai0-1, maitta0, here0, win0, lose0（33セリフ）。
- 文字はすべて `TEXT`（ja / en）、声のセリフは `VOICE_TEXT`（ja / en）。言語を足すときは両方に1つ足す。言語の決め方: `?lang=` → localStorage `kakurenbo-lang` → ブラウザの言語（日本語以外は英語）。AI の声は日本語のときだけ使い、それ以外は端末の読み上げ。
- 場面（`SCENES`）: かくれる物（絵文字）、かくれる どうぶつ、背景、かざり。かくれる物はステージを 3×3（横向きは 4×2）に分けたマスにばらまく。大きさは `--u`（ステージの短い辺の 1/100）で決める。
- かくれ方: どうぶつを物（.cov）の うしろ（z-index が下）に置き、上か横から `vis`（見える割合）だけ はみ出させる。`LEVELS` で 見える割合・ヒントまでの時間を決める。
- 写真モード: 写真を `object-fit: contain` と同じ計算で置き、かくれる子の下の部分に「同じ写真の同じ場所」を切りぬいた板（.pc、background-position で合わせる）をかぶせる。写真は長い辺 1400px の JPEG。かくれる場所は 0〜1 の割合で保存。写真モードは A より 0.1 多く見せる。
- C モード: おにさんは `moveOni`（%＋--u）で動く。見つかる確率は 1ぴき設定で 40%、ほかは 50%。見つからないときは 3〜4 か所さがして「まいった」。
- 拡大の防止（v0.2）: viewport の指定に加えて、400ms 以内の2回目の touchend・2本指の touchstart・gesture*・dblclick を preventDefault（おうちのかたへ と 顔の切りぬき は除く）。それでも拡大されたら visualViewport の resize で気づき、viewport を一瞬 maximum-scale=1.01 にして戻す（`resetZoom`）。まちがいさがしと同じ書き方。
- 保存: localStorage `kakurenbo-book`（ずかん：絵文字ごとの回数）、`kakurenbo-medal`、`kakurenbo-level`、`kakurenbo-voice`（`ai:jf_alpha` 標準 / `dev` / `off`）、`kakurenbo-sound`、`kakurenbo-me`、`kakurenbo-oni`。IndexedDB `kakurenbo`（ストア `voice`＝録音、`room`＝部屋の写真と場所、`face`＝顔 200px PNG）。
- 声の作り方は [ゆびで めいろ](meiro.md) と同じ（Kokoro fp16 で候補を作り、whisper-tiny で聞き取って一番合うものを選ぶ）。4種類×33セリフ＝132こ。116こは聞き取りが一致。合わなかった16こは、ほとんどが「いーち」「にーい」など短い数字（whisper-tiny が短い言葉を聞きまちがえやすい）と「くすくす／うふふ」。気になるときは耳で確かめて作り直すか、録音で差しかえる。道具は `/mnt/project-files/kakurenbo/tools/`（slots.py＝セリフ一覧, cand.py, asr.mjs, pick.py）。
- 課金: `<script src="../common/kakin.js">` を ゲームの script の前に読み、`Kakin.setup({game: 'kakurenbo', ...})`。🔒は `.kk-lock` クラス、さわったら `Kakin.ask()`、ぜんぶ版かどうかは `Kakin.full()`。むりょうの範囲は `FREE_SCENES`（`mori`）。お店のボタンは「おうちのかたへ」画面の `#kkSlot`。
