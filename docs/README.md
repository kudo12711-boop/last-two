## 技術メモ（全体）

- **リポジトリ** `kudo12711-boop/last-two`（Public）。`main` ブランチがそのまま GitHub Pages（https://kudo12711-boop.github.io/last-two/）になります。
  - `/index.html` … ラスト・ツー
  - `/machigai/`、`/todofuken/`、`/camper/`、`/meiro/`、`/tentsunagi/`、`/fukuwarai/`、`/kezuri/`、`/nukenuke-ring/`、`/kakurenbo/`、`/oukoku/`… それぞれ別のゲーム。ほかのゲームには影響しません。
  - `/games/` … 入口ページ（ゲームを公開したらここにもカードを足す）
  - `/docs/` … この記録
- 変更は作業ブランチ → PR → マージ の順。マージすると1〜2分で公開ページに反映されます。
- **プロジェクトの共有フォルダ** `/mnt/project-files/` に、各ゲームの HTML と作るための道具（`tools/`）があります。ゲームによっては、リポジトリの HTML がこの道具で作られたものなので、直すときはもと（src や tools）を直してから作り直します。各ゲームの技術メモを参照してください。
- Claude のページ（Artifact）の中ではカメラ、写真の選択、友だち対戦（PeerJS）がうまく動かないので、それらを使うゲームは GitHub Pages に置いています。
- この作業環境からは github.io のページを開けず、HuggingFace と GitHub Releases からのダウンロードもできません（AI の声は npm / PyPI 経由で作りました）。
- くどうさんは開発の専門用語になじみがないので、説明はやさしい日本語で、ジョーカーは「ババ」と呼びます。
