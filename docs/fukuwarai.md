# ふくわらい（幼児向け）

最終更新: 2026-11-09 ／ いまの版: v0.2（公開準備中）

## ひとことで

顔の上に まゆ・目・鼻・口を置いて、へんな顔を作って笑う福笑いです。用意した絵の顔のほか、家族やペットの写真から顔のパーツを自動で切り抜いて遊べます。

## 遊び方（いまの版）

- モードを選ぶ:
  - **かんたん**（2さい〜）: パーツが見えたまま。正しい場所のすぐ近くに置くと「ぴたっ」とくっつく（左右の目などは どちら側でもOK）。「ぴたっ」の強さは おうちのかたへ で つよい／よわい（最初）／なし を選べる。置いたパーツは指でつかんで、少しずつ好きな場所へ動かせる（つかんだ所がずれない）。
  - **めかくし**（4さい〜）: 最初に顔を よく見てから画面が暗くなり、置いたパーツは見えない（置いた場所に うすい点だけ）。全部置いたら「せーの！」ボタンで、パーツが1つずつ現れる。
- 顔を選ぶ: 絵の顔 4つ（おかめ・ねこ・くま・おに）と、写真で作った顔。
- 「しゃしんで つくる」: カメラで撮る か 写真を選ぶ → 顔を自動で見つけて まゆ・目・鼻・口に まるが付く → おうちの人が まるを確かめて「これで つくる」。パーツを切り抜いたあとは、まわりの肌の色でうめた のっぺらぼうの顔になる。写真の顔は8つまで保存。
- できあがったあとも、パーツを指で動かして細かく直せる（動かすと ゆらゆらが止まり、直した顔を もう一度アルバムに入れられる）。置ける範囲は 顔の外も含めた 画面の板全体。
- できあがり: パーツが ゆらゆら動き、「わはは！」の音と声。もとの顔に近いと「そっくり！」と紙ふぶき。「そっくりど ○%」と星。「こたえ」を押している間は もとの顔が見える。
- 「アルバムへ」で できた顔を保存（40まいまで）。アルバムから スマホに保存・共有、削除ができる。
- 日本語 / English 切りかえ。声は AI の声4種類（日本語）、スマホの声、なし。英語のときは スマホの声。

## 技術メモ

- リポジトリ `fukuwarai/index.html`（1ファイル）＋ `fukuwarai/voice/<声>/<key>.mp3` ＋ `fukuwarai/lib/`（顔を見つける仕組み）。
- 顔は 600×720 の座標。絵の顔は `makeDrawn()` で canvas に描いた土台（`base`）とパーツ（`P(type,id,x,y,w,h,draw)`、`tx,ty` が正しい位置）。`type` が同じパーツ（左右の目など）は入れかわってもよい（ぴたっ と点数の両方）。
- 写真: `lib/face-api.js`（@vladmandic/face-api 1.7.15、MIT、`lib/LICENSE-face-api.txt`）と `lib/model/`（tiny_face_detector と face_landmark_68）を リポジトリに同梱。写真を選んだときだけ読みこむ。すべて端末内で動き、送信しない。68点の目印から 目の傾きを水平に直して 600×720 に切り抜き（`fromLandmarks`）、パーツごとに だ円（`boxes`）を作る。見つからないときは中央に仮のだ円（`fallbackCrop`）。
- パーツ切り抜きは だ円で ふちをぼかす（`cutPart`）。土台は だ円の中を、8方向で いちばん近い外側の色を 距離で重みづけして うめ、少しぼかして ざらつきを足す（`inpaint`）。
- 点数: パーツごとに 正しい位置からの距離 d で `max(0, 1 - d/190)`、左右のペアは入れかえた方が高ければそちら。82%以上で「そっくり」。★は 90/70 で区切り。ぴたっ は `SNAP_R`（つよい70・よわい34・なし0、写真は×1.1）以内、設定は localStorage `fuku-snap`。置いたパーツの移動は `cv` の pointerdown/move/up（`bmove`、つかんだ所との差 dx,dy を保つ）。かんたんの とちゅう と できあがり後（`G.phase==='done'`）だけ動かせ、できあがり後に動かすと `G.calm` で ゆらゆらを止める。位置は `clampFace` で板の中に収める。
- 保存（localStorage）: `fuku-faces`（写真の顔: 600×720 JPEG と だ円、8つまで）、`fuku-album`（360×432 JPEG、40まで、いっぱいなら古いものから消す）、`fuku-mode` `fuku-voice` `fuku-sound` `fuku-lang`。
- 声: key は `look0/1` `blind0` `pick0/1` `put0-2` `snap0/1` `ready0` `seno0` `funny0-2` `good0/1` `photo0`。作り方は [ゆびで めいろ](meiro.md) と同じ（Kokoro fp16 で候補を作り、whisper-tiny で聞き取って選ぶ）。道具は `/mnt/project-files/fukuwarai/tools/`（slots.py, cand.py, asr.mjs, pick.py）。モデルは npm `kokoro-fp16-shards` の part0〜9 を つなげて kokoro-fp16.onnx にする。
- `ぴ` で始まる言葉（ぴたっと・ぴったり）は AI の声1（jf_alpha）が苦手で、聞き取りの一致が低め。気になるときは声2〜4に。
- この作業環境からは jsDelivr が開けないので、face-api は npm から取ってリポジトリに入れた。
