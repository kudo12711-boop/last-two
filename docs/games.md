## ひとことで

公開中のゲームをカードで並べて、選んで遊べる入口ページです。ゲームではなく「案内板」です。

## いまの中身

- 2つのまとまりに分けて並べています。
  - ちいさな子ども向け（2〜6さいくらい）: まちがいさがし、ゆびで めいろ、てんつなぎ、ふくわらい、もういいかい？ かくれんぼ、ちいさな おうこく、けずって なにかな？
  - みんなで・ひとりで: ラスト・ツー、ぬけぬけリング、都道府県パズル、キャンピングカー世界一周
- カードには、名前・ひとこと説明・対象年齢の目安・遊ぶ人数などの札がついています。押すとそのゲームが開きます。
- 右上で「日本語 / English」を切りかえられます。最初はスマホの言語設定に合わせ、選んだ言語は次回も覚えています。
- スマホの明るい／暗い表示に合わせて色が変わります。
- Claude のページでしか遊べないもの（チェイン・ノード、雪だるまパニック、ゆきどけ）はログインが必要なので、入れていません。

## 今後の予定

- 新しいゲームを公開したら、ここにも1枚カードを足す。
- アイコンは今は絵文字。ゲームの画面写真に変えると、もっとわかりやすくなります。
- 対象年齢はいまは Claude の目安です。実際に遊んでもらった感想で直します。
- ラスト・ツーのページ（いちばん上）からこの入口へのリンクはまだありません。必要なら足します。

## 技術メモ

- 1ファイルの HTML（`games/index.html`）だけ。外部の読み込みはありません。
- ゲームの一覧は script の `GAMES`（id・URL・絵文字・背景色・まとまり）、文字は `TEXT`（言語ごとの辞書）。ゲームを足すときは両方に1つずつ、言語を足すときは `TEXT` に1つ足します。
- 言語の決め方: URL の `?lang=ja|en` → 前回選んだもの（localStorage `games-lang`）→ ブラウザの言語（日本語以外は英語）。
- リンクは相対パス（`../machigai/` など）なので、リポジトリ名が変わっても動きます。
- 課金: `../common/kakin.js` を読み、`Kakin.setup({game: 'games', noFull: true})` でパスだけを案内。文字は TEXT の `pass` `passBtn` `passOn`。
