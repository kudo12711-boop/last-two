## いまの中身

- 2つのまとまりに分けて並べています。
  - 子ども向け（2〜8さいくらい。11/25 に「ちいさな子ども向け 2〜6さいくらい」から名前を変えた）: まちがいさがし、ゆびで めいろ、てんつなぎ、ふくわらい、もういいかい？ かくれんぼ、ちいさな おうこく、けずって なにかな？、そして かくしURL の ひらがな あそび、おなじ？ ちがう？、どうぶつ あみだくじ、ころころ ゆきだま、ぽーん！ ボールなげ（🧪 ためし版）、都道府県パズル、ふしぎな いきもの ずかん
  - みんなで・ひとりで: ラスト・ツー、ぬけぬけリング、キャンピングカー世界一周
- かくしURL のゲームは、URL を かえずに そのまま のせ、カードに「🧪 ためし版」（英語は「🧪 Trial」）の札を付けます。ゲームのページの 検索よけ（noindex）は そのまま。キャンピングカーの「ためし動画」（try-69e9755fd8bf7873）は ゲームではないので のせていません。
- カードには、名前・ひとこと説明・対象年齢の目安・遊ぶ人数などの札がついています。押すとそのゲームが開きます。
- 右上で「日本語 / English」を切りかえられます。最初はスマホの言語設定に合わせ、選んだ言語は次回も覚えています。
- スマホの明るい／暗い表示に合わせて色が変わります。
- Claude のページでしか遊べないもの（チェイン・ノード、雪だるまパニック、ゆきどけ）はログインが必要なので、入れていません。

## 今後の予定

- 新しいゲームを公開したら、ここにも1枚カードを足す。
- アイコンは今は絵文字。ゲームの画面写真に変えると、もっとわかりやすくなります。
- 対象年齢はいまは Claude の目安です。実際に遊んでもらった感想で直します。
- ラスト・ツーのページ（いちばん上）からこの入口へのリンクはまだありません。必要なら足します。

## 技術メモ

- 1ファイルの HTML（`games/index.html`）だけ。外部の読み込みはありません。
- ゲームの一覧は script の `GAMES`（id・URL・絵文字・背景色・まとまり）、文字は `TEXT`（言語ごとの辞書）。ゲームを足すときは両方に1つずつ、言語を足すときは `TEXT` に1つ足します。
- 言語の決め方: URL の `?lang=ja|en` → 前回選んだもの（localStorage `games-lang`）→ ブラウザの言語（日本語以外は英語）。
- リンクは相対パス（`../machigai/` など）なので、リポジトリ名が変わっても動きます。
- かくしURL のゲームを足すとき: `GAMES` に `{id, url:"../try-…/", hidden:true, …}` を1行、`TEXT` の各言語の `games` に説明を1つ。`hidden:true` で「ためし版」の札（`TEXT.*.trial`）が付く。言語ごとに開く先を変えたいときは `urlEn`（英語のときだけ使う）。
- 課金: `../common/kakin.js` を読み、`Kakin.setup({game: 'games', noFull: true})` でパスだけを案内。文字は TEXT の `pass` `passBtn` `passOn`。

- アプリの準備（2026-11-19）: `manifest.webmanifest`（アプリの名札）、`app/` の仮アイコン、`app-files.json`（アプリとして開いたときに まとめて保存するファイルの一覧）、`<head>` に `common/app.js`（オフライン）と `common/hikkoshi.js`（games.hajimaruyo.com への記録の引っ越し）。ファイルを足したり変えたりしたら `node tools/make_app.cjs --no-icons` で一覧を作りなおす。くわしくは [app-plan.md](app-plan.md)。
