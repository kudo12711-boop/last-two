# ラスト・ツー

最終更新: 2026-10-25 ／ いまの版: v1.3

## ひとことで

ババ抜きで一番盛り上がる「最後の2人」の場面だけを遊ぶ、表情の読み合いゲームです。カメラで自分の表情を読み取り、キャラクターがまねします。CPU とも、友だちとオンラインでも遊べます。

## 遊ぶ場所

- スマホ・iPad・パソコン（カメラも使えます）: https://kudo12711-boop.github.io/last-two/
- LINE などアプリの中で開くとカメラが使えないので、ChromeやSafariで開いてください（画面上に「ブラウザで開く」ボタンが出ます）。
- 古い Claude のページ（カメラは使えません）: https://claude.ai/artifact/WMPypzjDa8EjpMUpyDjHzx
- ファイル: `/mnt/project-files/last-two/last-two.html`（もと）と `index.html`（公開用）

## 遊び方（いまの版）

- **引く番**: 相手の札をタップすると指さしになり、相手の顔色が変わる。もう一度タップで引く。相手がババを持っていると「じっくり見る」が働き、指が相手の札を1枚ずつ自動でまわるので、そのたびに顔を見られる（1枚あたり 2枚=約2.6秒、3枚=2秒、4枚=1.6秒、5枚以上=1.3秒）。途中でタップすればそこで止まる。
- **引かれる番（CPU戦）**: 「並べかえタイム」（約4秒、「並べかえ完了」で早く終われる）→「にらみ合いタイム」（約6秒、札は動かせず相手の指がうろうろ、顔だけで勝負）。
- 相手の指が自分のババに来ると、「ドクン、ドクン」と音がしてババが赤く光る（Android は本体もふるえる。iPhone は音と表示だけ）。「音 オフ」で止まる。
- ババを引いてしまったら、自動で手札がまざる。
- **CPU**: ポン太（顔に出やすく正直）、ミケ（正直なときとでたらめなとき）、クロ（顔色でウソもつき、あなたのクセを覚える）。ミケとクロはカメラに映るあなたの表情も読む。
- **友だち対戦**: 「友だちと」→「部屋を作る」→ LINE・共有・QRコードで招待。2人そろったら両方が「準備OK！」を押すと始まる。カメラをつけると、キャラで表情をまねるか、本物の映像を見せるかを選べる。自分が引く番は相手の顔が大きくなり「あなたの番！」と出る。
- **きせかえ**: コイン（勝ち30・負け10、はじめての友だちと遊ぶと2人とも+100）で、キャラ（ひと・ねこ・くま・ロボ・うさぎ・おばけ）、カード柄、マンガ効果を買える。シーズン1「はじまりの卓」のパス（レベル20まで）。友だち3人と遊ぶとカード柄「なかよし」。
- 一度遊んだ友だちはリストに残り、「また遊ぶ」ですぐ部屋を作れる。

## お金のこと（2026-10-23 くどうさんが採用）

- きせかえ（キャラ・カード柄・マンガ効果）＋ シーズンパス。
- 広告は試合が終わったときだけ（パスを持っていると消える）。勝ち負けに関わる課金はしない。
- いまはすべて「仮」で、お金は動きません。本物にするときは、アプリにして App Store / Google Play のアプリ内課金を使い、コインはサーバー（Firebase など）で管理します。日本では買ったコインに資金決済法がかかるので、始める前に確認が必要です。

## 技術メモ

- リポジトリ `kudo12711-boop/last-two` の一番上の `index.html` が公開ページ（GitHub Pages、`main` ブランチ）。もとは `/mnt/project-files/last-two/last-two.html`（Artifact 用の中身だけ）。`index.html` は、その前に `<!doctype html>…<body>`（viewport、safe-area の余白、`[hidden]{display:none!important}`）を足し、後ろに `</body></html>` を付けたもの。更新するときは last-two.html を直してから index.html を作り直します。
- 表情の読み取りは MediaPipe 系の顔ランドマーク（ブラウザ内で動き、映像はどこにも送らない）。キャラは SVG。
- 友だち対戦は PeerJS の無料クラウドサーバー（アカウント不要、WebRTC）。部屋を作った側（ホスト）がゲームの正しい状態を持つ。顔のパラメータは約10回/秒で送る。メッセージ例: `t:'mode'`（映像/キャラ切りかえ）、`aim`（指の位置、-1で消す）。Artifact の中では動かず、GitHub Pages でのみ動く。
- 招待URL: `https://kudo12711-boop.github.io/last-two/?room=xxxxx&openExternalBrowser=1`（LINE が外部ブラウザで開く指定）。Android のアプリ内ブラウザには `intent://` で Chrome を開くリンク。
- 保存: localStorage `lasttwo-inv`（持ち物）、`lasttwo-pid`（プレイヤーID）。友だちリストも端末の中だけ。
- QR コードは cdnjs の qrcodejs。心臓の音は WebAudio で合成（スマホで聞こえる中くらいの高さ）。
- Claude は GitHub でリポジトリを新しく作ったり、Pages をオンにしたりはできません（くどうさんの操作が必要）。
