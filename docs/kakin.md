# 課金のしくみ（全ゲーム共通・おためし版）

最終更新: 2026-11-03 ／ いまの版: v0.1（公開前）

## ひとことで

子ども向けゲームと都道府県パズルに入れた、共通の「お金のしくみ」です。どのゲームも **すこし むりょうで遊べて、「ぜんぶ版」（ゲームごとの買い切り）か「👪 ファミリーパス」（月ごと・ぜんぶのゲーム）で ぜんぶ遊べる** 形にそろえました。いまは「買うふり」で、お金は動きません。

## 生まれたきっかけ

2026-11-03、くどうさん「ここで開発しているゲームは全て課金する予定です。まだ課金するシステムが組み込まれていないゲームについて組み込むようにしてください。開発、組み込み、課金を組み込む開発をしてください。」

## 売り方（仮の値段）

| 商品 | 値段（仮） | 中身 |
|---|---|---|
| 各ゲームの「ぜんぶ版」 | 買い切り 480円 | そのゲームの 🔒 が ぜんぶ外れる |
| 👪 ファミリーパス | 月 380円 | 子ども向けゲーム＋都道府県パズルが ぜんぶ遊べる。キャンピングカーの追加ルートもふくむ。いつでも更新を止められる |

子ども向けの約束:

- 広告は出さない。
- 買う画面の前に かならず「おとなの確認」（かけ算の答えを4つから えらぶ）。字が読めない小さい子は進めない。
- 遊んでいる とちゅうに 買い物を すすめない。🔒をさわったときだけ「おうちの ひとに きいてみてね」と出る。
- 勝ち負けや上手さに関わるものは売らない（ふえるのは 絵・ばめん・キャラなどの遊べる中身）。

## これから

- 値段を決める（いまは仮）。ゲームごとに むりょうの量が多すぎ／少なすぎないか、知り合いに遊んでもらって決める。
- 本物の支払いにする（アプリ化のとき）。くどうさんのアカウントが必要: Apple の開発者登録（年1万2千円ほど）と Google Play（最初に約4千円）。アプリ内課金（App Store / Google Play）を使う。ウェブのままで売るなら Stripe などの決済サービスのアカウントも必要。
- 「買ったもの」を端末ではなくアカウントで覚える（機種変更しても残るように）。そのときは Firebase などのサーバーが必要。

## 技術メモ

- ファイル: `common/kakin.js`（1つだけ、ほかに必要なものなし）。各ゲームは `<script src="../common/kakin.js"></script>` をゲームの script の前に読む。
- 使い方: `Kakin.setup({game, lang: () => 'ja', name, free, full, onChange})`。`Kakin.full()` で「ぜんぶ版 か パス」を持っているか、`Kakin.ask()` は 子ども向けの「🔒 おうちの ひとに きいてね」画面、`Kakin.open()` は おとなの確認 → お店、`Kakin.parentButton()` は「🔓 ぜんぶ あそぶ（おうちのかたへ）」ボタンを作る。`noFull: true` で パスだけを案内（入口ページ・キャンピングカー）。🔒の見た目は `.kk-lock` クラス（右上に🔒）。
- 保存: localStorage `asobi-kakin-v1` = `{owned: {'full:meiro': 買った時刻, ...}, pass: {since, until, renew}}`。同じサイトのゲームどうしで共有されるので、パスは どのゲームで買っても ぜんぶに効く。パスは30日ごと。おためし版では「更新を止める」まで自動で のびる。
- 本物の支払いへの差しかえ口: `Kakin.provider = {buy(product) → Promise<boolean>, restore() → Promise<id[]>}`。いまは すぐ成功する「ふり」。値段は `PRICES`（`full` 480、`pass` 380）。
- テスト: お店の いちばん下の「おためしの購入を ぜんぶ消す」で もとにもどせる。
- 文字は `TEXT`（ja/en）。言語を足すときは TEXT に1つ足す。
