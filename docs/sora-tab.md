# そらタブ（英語名 Sky Tab・仮）

最終更新: 2026-11-12 ／ いまの版: v0.1（Chrome 拡張の試作、2026-11-12）

## ひとことで

ブラウザで新しいタブを開くたびに、いまの時刻と天気に合わせた空と景色が広がる、Chrome（と Edge）の拡張機能です。大きな時計、日付、天気、検索ボックスつき。空も景色もプログラムが描くので、画像ファイルも AI も使いません。実用ツールの2つめ（[moyou.md](moyou.md) と同じ描く部品を使う）。

## 使う場所

- お試しページ（公開後、ふつうのページとして見られる）: https://kudo12711-boop.github.io/last-two/sora-tab/newtab.html
  - 時刻や天気を変えて見る: `?hour=18.5&weather=rain&land=sea&lang=en`（weather は clear / cloudy / rain / snow / fog / storm、land は mountains / sea / hills / city / none）
- 拡張機能の zip（公開後）: https://kudo12711-boop.github.io/last-two/downloads/sora-tab.zip（コピーは `/mnt/project-files/sora-tab/sora-tab.zip`）
- ファイル: リポジトリの `sora-tab/`

## 自分のパソコンの Chrome に入れる方法（お店に出す前のお試し）

1. zip をダウンロードして、ダブルクリックで開く（フォルダになる）。
2. Chrome のアドレス欄に `chrome://extensions` と入れて開く。
3. 右上の「デベロッパー モード」をオンにする。
4. 「パッケージ化されていない拡張機能を読み込む」を押して、1 のフォルダを選ぶ。
5. 新しいタブを開くと、そらタブになる（はじめに Chrome が「この変更を保持しますか」と聞いてくるので「保持」）。

## できること（v0.1）

- **空**: 時刻で空の色、太陽・月の位置、星が変わる（5分ごとに描きなおし）。天気は はれ・くもり・あめ・ゆき・きり・かみなり。あめ・ゆきは粒が動き、かみなりは ときどき光る（せっていで止められる）。
- **けしき**: やま・うみ・おか・まち・そらだけ。ふだんは「日がわり」（日付で変わる）。夜のまちは窓に明かり、うみは太陽の光の道。
- **時計**: あいさつ（おはようございます／こんにちは／こんばんは／おやすみなさい）、日付と曜日、天気と気温。12時間表示も選べる。
- **検索**: Chrome にふだん設定している検索サイトで検索（`chrome.search`）。せっていで消せる。
- **天気の場所**: 「いまの場所を使う」か、都市の名前でさがす（Open-Meteo の地名さがし）。「天気を使わない」も選べる。天気は30分ごとに取りなおす。
- **ことば**: 日本語・英語（自動で選ぶ。せっていで変えられる）。

## 約束ごと

- 天気を使うときだけ、場所（緯度・経度）を Open-Meteo（無料・登録なし）に送る。それ以外は端末の中だけ。
- 拡張機能がお願いする権限は「保存（storage）」と「検索（search）」だけ。閲覧履歴などは読まない。

## 技術メモ

- Chrome 拡張（Manifest V3）。`manifest.json` の `chrome_url_overrides.newtab` で新しいタブを `newtab.html` にする。権限は `storage` と `search` だけ。Open-Meteo は誰からでも読める（CORS が開いている）ので、`host_permissions` はいらない。
- 拡張のページではページの中に直接スクリプトを書けない（CSP）ので、`newtab.js` を別ファイルにしている。
- 空は `engine.js`（`moyou/engine.js` のコピー）の `type:'sky'`。**engine.js は moyou 側を直して `sh sora-tab/build.sh` でコピー**（同時に `downloads/sora-tab.zip` も作り直す）。
- `newtab.js`: 設定は `chrome.storage.local`（ふつうのページでは localStorage）のキー `soratab-v1` = `{lang, land, h12, showSearch, anim, place:{name,lat,lon}, wx:{kind,temp,at}}`。天気コードの変換は `kindOf()`（WMO の番号）。雨・雪は `#fx` の canvas で動かし、タブが見えないときは止める。
- アイコン（`icons/`）も engine.js で描いた空から作った（夕方・やま）。
- 名前と説明は `_locales/en` と `_locales/ja`（ブラウザの言語で切りかわる）。
- この作業環境からは Open-Meteo につながらないため、天気の取得はテストでは仮の返事に置きかえて確認した（キャンピングカーで同じ API を本番で使っている）。拡張としての読みこみと、新しいタブがそらタブになることは Chromium で確認済み。
