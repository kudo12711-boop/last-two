# ちいさな おうこく（プリンセスになれるゲーム）

最終更新: 2026-11-03 ／ いまの版: v0.1

## ひとことで

プリンセス・おうじさま・きしさま・さむらいさまの中から自分を選んで着せかえし、小さな王国の村の人たちの「おねがい」をかなえるゲームです。おねがいをかなえるとハートがたまり、お城や庭が少しずつにぎやかになります。自分の顔写真をはめた肖像画も作れます。

## 生まれたきっかけ

2026-11-03、くどうさん「女の子向けの、プリンセスになれるゲームを考えたいです。男の子向けにも同じようなゲームができれば良いですが、女の子に特化してもいいです」。

Claude が3案を出しました。

- A. 着せかえ ＋ 短いおはなし（選んだ答えで結末が変わる）
- B. 小さな王国のプリンセス（毎日村の人からおねがいが届き、お城が育つ）
- C. 自分の顔写真で肖像画を作る（おまけ機能）

おすすめの「B を中心に A の着せかえと C の肖像画」を、くどうさんが「はい」で採用。男の子向けは「1本の中で王子・騎士も選べる」を選び、さらに「男の子向けには侍も選べるようにして下さい」。

## 遊び方（いまの版）

- **だれになる？** プリンセス・おうじさま・きしさま・さむらいさまの4人から選ぶ。侍は「ひがしの くに」から来た仲間という設定で、最初のあいさつも少し変わる。
- **きがえ**: ふくの色、かざり（ティアラ・王冠・騎士のかぶと・はちまき など）、かみがた、かみの色、はだの色、なかま（ペット）、名前。役ごとの決まりはなく、騎士にティアラなども自由。🔒のものは遊ぶともらえる。
- **かお（しゃしん）**: 自分の顔写真を選び、指で動かして丸に合わせると、キャラクターの顔が自分の顔になる。写真はスマホの中（localStorage）だけに保存し、どこにも送らない。
- **おうこく**: お城の前に自分が立ち、村の6人のうち3人の頭に「!」が出ている。タップするとおねがいを読み上げてくれる。
- **6つのおねがい（ミニゲーム）**。どれも失敗で終わらず、2〜3回まちがえると正解が光る。
  - パンやの くまさん: お手本と同じくだものをケーキにのせる
  - はなやの うさぎさん: はちをタップして水をあげ、花をさかせる
  - こどもの ドラゴン: 「さむい」「のどがいたい」などに合うもの（マフラー、お茶…）をあげる
  - ふくろうの おばあさん: 木の中から、なくしもの（めがね・かぎ…）をさがす
  - ゆうびんやの ペンギン: 手紙と同じ色の家に届ける
  - ひがしの くにの たぬきさん: ちょうちんの色のならび（AB・AAB・ABC）の続きを当てる
- **ほうび**: 1回で❤️2（はじめてのおねがいは❤️3）。はじめてかなえた人からは、おれいにきせかえ（リボン、花かんむり、ドラゴンのなかま…）がもらえる。
- **お城が育つ**: ❤️がたまると、はた → おはなばたけ → ふんすい → ちょうちん → たかい とう → にじ → ききゅう → ひがしの もん → はくちょうの いけ → はなび（夜空になる）の順にふえる（全10こ、❤️32でぜんぶ）。
- **おてがみ（1日1回）**: 📮から王さまのプレゼント（ペット、髪型、色など）。毎日開きたくなる仕掛け。全部もらうと❤️3。
- **しょうぞうがの へや**: 背景の色を選んで「かいてもらう」と、金のがくぶちに入った肖像画（名前と日付入り）ができ、かべに飾られる（12まいまで）。ほぞんボタンか長押しでスマホに保存できる。
- こえ（読み上げ）あり／なし、日本語／英語は ⚙️ で切りかえ。

## 技術メモ

- 1ファイルの HTML（`oukoku/index.html`）だけ。外部の読み込み・画像ファイルはなし。キャラクター・お城はすべて SVG を JavaScript で組み立て、村の人と小物は絵文字。
- キャラクター: `avatarSVG(look, role, opt)`（viewBox 0 0 200 280、頭の中心 (100,80) 半径38）。`opt.layer` は `all` / `base`（かざり以外）/ `top`（かざりだけ）。肖像画は base → 写真 → top の順に canvas へ重ねて描く（Safari で SVG 内の画像が描けないことがあるため分けている）。
- データ: `ROLES`、`SKINS`、`HAIRS`、`HAIRC`、`COLORS`、`ACCS`、`PETS`。最初から使えるものは `FREE`、はじめてのおれいは `FIRST_GIFT`、おてがみの中身は `MAIL_POOL`、お城の飾りと必要な❤️は `DECOS`、村の人の位置は `RES`。
- ミニゲームは `GAMES.<id>(area, 文字, ctx)`、終わったら `finishGame()`。おねがいをかなえるとその人は外れ、ほかの人から1人ふえる（いつも3人）。
- 文字はすべて `TEXT`（ja / en）。言語の決め方は URL `?lang=` → 前回（localStorage `oukoku-lang`）→ ブラウザの言語。
- 保存: localStorage `oukoku-save`（役、きせかえ、❤️、もらったもの、おねがい、おてがみの日付、こえ）、`oukoku-face`（顔写真 200px JPEG）、`oukoku-portraits`（肖像画 480×640 JPEG、12まいまで。入らないときは古いものから消す）。
- 読み上げはブラウザの speechSynthesis、効果音は WebAudio。
- お城の絵は viewBox 400×600 を横幅に合わせて下寄せ（`xMidYMax meet`）、あまった所は空と草の色でうめる。
