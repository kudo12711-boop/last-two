# キャンピングカー世界一周

最終更新: 2026-11-12 ／ いまの版: 2026-11-12 の「ひろいもの帳」まで（v0.1 → v0.2 → 以降は機能ごとに追加）

## ひとことで

放っておくと進む「放置型」の旅アプリです。アプリを閉じているあいだもキャンピングカーが走り、次に開くと、進んだ先の「いまの」時刻・天気・気温に合わせた車窓の景色が見られます。

## 遊ぶ場所

- 英語で開く: https://kudo12711-boop.github.io/last-two/camper/?lang=en （日本語にもどすには ?lang=ja か、設定の「ことば」）
- ファイル: `/mnt/project-files/camper/index.html`、部品は `/mnt/project-files/camper/tools/`

## 生まれたきっかけ

- 2026-10-24、くどうさんが「まだ作っていないメジャーなジャンルは？」と質問 →「放置ゲームとは？」と続き、そのあと依頼。
- 依頼:「世界中をキャンピングカーで旅するゲーム。車窓から見える世界各地の景色を、その場所の天気や気温に応じて見られるように。移動速度に応じて、前回開いてから今回開くまでの距離が決まり、その場所の景色が見られるように」。
- 追加の希望:「海の上の移動は一工夫して楽しめるように」「ルートの選択にも一工夫」。

## 遊び方（いまの版）

- はじめに出発地（20の町、日本は東京・大阪・福岡・札幌）と速さ（時速20/60/100/300km）を選ぶ。時速60kmなら一周約27日。出発地に戻ると1周。
- 開くと「おかえりなさい！ ○時間で○km進みました」と、通った町や見かけた生きものを教えてくれる。
- 車窓: 太陽・月・星は本物の天文計算、天気と気温は本物（取れないときは「（予想）」）。雨のしずく、雪、霧、雷、季節の紅葉、7種類の土地、名所約40か所。
- 海の上: フェリーのデッキから海。風が強いと船がゆれる。イルカ・クジラ・ウミガメなどが出て図鑑に記録。手紙入りのボトルや貝がら・シーグラスなどの「ひろいもの」が流れてくる。タッチすると拾えて、記録の「🐚 ひろいもの」タブ（ひろいもの帳）にたまる（全11種類。海ごとに出る物がちがい、まだの物は「？」とどの海で見つかるかのヒント）。ボトルの手紙は、拾った日・場所と中身ごと保存して読み返せる。
- 分かれ道4か所（北京・ウィーン・リスボン・ロサンゼルス）: 行き先のいまの天気と季節のおすすめつき。選ばずに着くと運転手のおまかせ。
- 設定（旅の途中でいつでも変更可）: 窓のデザイン6種、電柱の表示オン・オフ、速さ、「町に着いたら」（止まらない／次の町で1回止まる／毎回止まる）、音量。
- 窓辺の小物は、その場所の時間帯・気温・雨で入れかわる（朝コーヒー、夜ラーメン、雨の日かさ…）。
- 観光モード（町で停車中に「🗺 観光する」）: 名所めぐり（町ごとに3か所、現実の時間で1〜3時間）、ご当地グルメ、おみやげ（窓辺に2つまで）、地元のことば（🔊で発音）、泊まり方（キャンプ場・ホテル・車中泊）。
- 旅の引き継ぎ: 設定の「💾 引き継ぎコード」で、コードかファイルに保存・復元。7日以上保存していないとお知らせ。
- 音: エンジン、雨、風、波、町、鳥・虫・カエル、カモメ、たき火、雷。
- 追加ルート（買うふり）: 北欧とオーロラ、アフリカと南アメリカ、南太平洋とオーストラリア。1つ480円・セット980円（仮）。
- 絵はがき（下の「📷 絵はがき」）: いま窓から見えている景色に、町の名前・日付と現地の時刻・天気・走ったきょりを入れた1枚の絵を作る。先に大きく見せて、「保存・送る」でスマホは送り先を選ぶ画面（LINE・写真に保存など）、PCは「画像を保存する」（ファイル名に日時が入る。LINE にはダウンロードフォルダの画像をトーク画面にドラッグして送る）。「撮りなおす」もできる。
- 全画面（窓の右下「⛶ 全画面」、または車窓の景色をダブルクリック／スマホは2回つづけてタップ。全画面中にもう一度で元の画面へ）: 景色を画面いっぱいに。左上に現在地・時刻・天気・次の町まで、右上に小さな地図（ふだん半透明、タップでくっきり、もう1回で大きな地図、8秒で半透明に戻る）。ℹ️で表示の量を切りかえ。画面が消えないようにする。
- ながめるモード（窓の右上「🖼 ながめる」）: ボタンも文字も消して景色だけを流し、置き時計のように飾る。大きな時計（スマホの時刻）と日付、小さく現在地と天気。時計の位置は焼きつき防止で数分ごとに少し動く。夜11時〜朝6時は少し暗く。タップで「もどる／時計あり・なし／夜は暗く／音」のメニュー。お知らせは出さない。
- スマホの待ち受け画面（ロック画面）に流すのは、Webアプリではできない（スマホの仕組み上）。代わりがながめるモード。
- 町の情報カード: 画面上の地名（ⓘ）をタップ。国、豆知識、名所、名物、おみやげ、スタンプ、あいさつ（🔊）。
- 地図: −／＋の5段階（世界全体〜すぐそば）、指でなぞって移動、ピンチで拡大縮小、📍で現在地へ。
- 町に着いて停車すると「○○に到着！」の画面が出て、「🗺 観光する／観光しないで出発する／あとで」を選べる。停車中は青い帯の「観光する」が光る。全画面のときも下に「🗺 観光する」ボタンが出る。
- 窓辺の小物にマウスを合わせる（スマホはタップ）と説明が出る。飾ったおみやげは「どこの観光で買ったか・いつ手に入れたか・そのとき行った所」も出る（日付は 11/11 以降に買ったものから）。
- 観光の名所カード、町の情報カード、記録の「観光」には「📖 くわしい説明」（ウィキペディア）と「🗺 地図で見る」（グーグルマップ）のリンクがある。名前が一般的な名所（市場を歩く など）は、町の説明を出す。
- 本物の写真: 到着画面、観光の画面（町の写真＋名前のはっきりした名所とグルメのカード）、観光から帰ったとき、町の情報カード、記録の「観光」「グルメ」に、ウィキペディアの自由に使える写真を出す。写真の下に出どころ（ページ名）を表示。おみやげも写真つき（観光の画面、買ったとき、記録、町の情報、窓辺の説明）。名前で見つからないときは「○○の置物」の○○で探す。見つからない・通信できないときは写真なしで今までどおり。
- 全画面で停車中は、画面の下に「🅿️ ○○で停車中／🗺 観光する（光る）／▶ 出発」のカードが出る。
- 窓辺の朝・昼・夜ごはん（🥐🍙🍜）は、近くの町の名物に変わる（説明に「○○の名物でお昼ごはん」）。
- 地図を「地方」まで拡大すると細かい陸地の線（land50.txt）、「ちかく」「すぐそば」と全画面の小さな地図ではもっと細かい線（land10.txt）を読みこむ。
- パソコンで全画面にしたとき: マウスを動かすとボタンがまた出る。Esc キーでもどれる（最初に案内が出る）。

## これから

- 本物の天気が取れているか、くどうさんの端末で確認（「（予想）」と出ていないか）。作業環境からは天気の取得を試せていません。
- 有料化の候補で残っているもの: 「あと2時間でパリに着きます」のようなお知らせ、季節限定の名所・おみやげ、絵はがきを LINE で送る。
- アフリカと南米のルートは時速60kmで約18日と長いので、長すぎれば短くする。
- 本物の支払いはアプリにするとき（開発者登録が必要）。

## 技術メモ

- 部品: `tools/data.js`（ルート・町・豆知識）、`tools/sight.js`（観光の中身: COUNTRY, CITY_C, CITY, GENERIC）、`tools/main.js`（本体）、`tools/src.html`（ひな形）、`tools/land.txt`（世界の陸地マップ）。`python3 tools/build.py <出力先>` で1つの HTML にまとめ、リポジトリの `camper/index.html` に置く。
- 天気は Open-Meteo、地名は BigDataCloud（どちらも無料・キー不要）。
- 写真: ja.wikipedia.org の API（prop=pageimages, pilicense=free）を画面から直接呼ぶ。まず題名で探し、なければ検索の上位。結果は localStorage `camper-img` に400件まで覚える（見つからなかったものも覚える。通信エラーは覚えない）。同時に3件まで。
- 陸地: 埋めこみの land.txt（110m）に加え、camper/land50.txt（Natural Earth 50m、0.05度）と camper/land10.txt（10m、点の間を約0.025度以上に間引き、約1.9MB）を拡大時に読みこむ。作り方は tools/make_land_detail.js（npm の world-atlas と topojson-client）。
- 描画の重さ対策: キャンバスの画素数は約220万までにしぼる。1コマに14ms以上かかると画素数を3割ずつ下げ、下限なら1コマおきに描く（main.js の resize と frame）。
- 保存: localStorage `camper-trip-v1`（旅の状態: startKm, startName, laps, stopMode, parked, stay, spots, food, gifts（11/11 から at=買った日時・from=その町で行った名所）, shelf, words, lodges, backupAt など）、`camper-frame`、`camper-poles`、`camper-sound`、`camper-vol`、`camper-owned`（買ったルート。リセットしても残る）、`camper-fsinfo`（全画面の表示量）、`camper-mapz`（地図の拡大段階）、`camper-gaze`（ながめるモードの時計・夜の暗さ）。
- 英語対応（11/11）: `tools/en.js` の `EN_T`（日本語→英語の辞書、約1200語）を build.py が DATA に入れる。main.js の先頭で言語 `LG` を決める（`?lang=` → localStorage `camper-lang` → `games-lang` → ブラウザの言語）。`J(日本語, 英語)` で画面の文、`tr(s)` でデータの名前を訳す。町・名物・おみやげの名前は保存のキーなので日本語のまま持ち、表示のときだけ訳す。英語のときはウィキペディアを en に、写真の覚えは `camper-img-en`。新しい町や名物を足したら en.js にも英訳を足すこと。
- ひろいもの（11/12）: main.js の `FINDS`（絵・名前・英語名・説明・出る海・出やすさ）。海の出来事 `bottle` が出るとき `pickFind(海域)` で中身を決める（ev.item）。保存は `st.finds`（id → n, first, last。where は日本語の町の名前の配列）と `st.letters`（新しい順、300通まで。about=手紙に書かれた町）。この機能より前に拾ったボトルは本数（st.bottles）だけ。
- 引き継ぎコードは `CAMPER1-` ＋ deflate ＋ base64url。
