# ふしぎな いきもの ずかん（英語名 Curious Critters・仮）

最終更新: 2026-11-26 ／ いまの版: v0.6（なきごえ、おねがい）。v0.5（ごはんで かならず 見た目が かわるように 直した、2026-11-25）

## ひとことで

くさむらで ふしぎな生きものに出会い、たべものや なでなでで なかよしになって ずかんに集めるゲームです。2ひきを近づけると たまごが生まれ、両方の特徴をまぜた 世界に1ぴきだけの子どもが生まれます。生きものも景色も、絵のファイルを1枚も使わず、すべてプログラムで描いています。

## 生まれたきっかけ

2026-11-12、くどうさんが「キャンピングカー世界一周は景色を画像なしで全部プログラムで描いている」と知り、その描き方を生かした新しいゲームを考えたいと相談。条件は「Claude をアプリの中で呼ばない方式（前もって描き方を書いておき、ネット不要・費用ゼロ）」。

- くどうさん「1のみで、できるアプリを何か面白そうなのを提案してもらえませんか？3つぐらい。」

## 遊び方（v0.1）

1. **すみかを えらぶ**: のはら・うみ・もり（むりょう）、ゆきやま・かざん・よるのもり（ぜんぶ版 🔒）。
2. **さがす**: 指で景色を左右にスワイプ（◀ ▶ ボタンや矢印キーでも）。ときどき くさむら（うみは海藻、かざんは岩、よるのもりは光るキノコ）が ゆれて ★ が光るので、タップすると生きものが飛び出します。
3. **なかよくなる**: 下の6つのたべもの（🍎🐟🌰🍯🍓🥕）をタップしてあげるか、生きものを指でなでます。ハートが5つたまると なかよし。生きものごとに「すきな たべもの」が1つあり、それをあげるとハート2つ（ずかんにも すきなものが記録される）。はじめは もじもじ（よそ見して ふるえる）していて、なかよくなると にこにこします。
4. **ずかん**: 「いきもの」タブで集めた生きもの（番号・名前・★めずらしい・🥚たまご生まれ）。タップすると大きく見られて、名前の変更、たまごへ が使えます。「ぶひん」タブで 見つけた部品の数（「なし」をのぞく 48こ中いくつ）と、まだ見つけていない部品の ？？？（その場所にしかいない部品は「よるのもりに いる」などのヒント）。
5. **たまご**（2ひき以上で使える）: 下のボタンで2ひきえらび、指で1ぴきを もう1ぴきに近づけると ハートが出て たまごが生まれます。たまごを3回トントンすると われて子どもが生まれます。

## 生きものの しくみ

- 8つの部品の組み合わせ: からだ7・もよう7・め6・くち6・あたま9・しっぽ7・あし5・はね5（「なし」もふくむ）。これに 色2つ（からだ・アクセント）、あざやかさ、明るさ、大きさ、すきな たべもの。組み合わせは 数十万とおり以上。
- **すみかごとに 出やすい部品と色**: うみ は うねうね足・さかなのしっぽ・ひれ・青系、もり は ふたば・はっぱしっぽ・緑や茶色、ゆきやま は ふわふわしっぽ・白っぽい色、かざん は つの・きば・とげとげ・赤系、よるのもり は ひかる め・こうもりの はね・むらさき系。
- **その場所にしか いない部品**: ひかる め（よるのもり）、うねうね足・さかなのしっぽ・ひれ（うみ）、こうもりの はね（よるのもり・かざん）、つの（かざん・ゆきやま）。ほかの場所では、たまごの へんか でしか出ません。
- **めずらしい部品 ★**: おほしさま・にじいろ もよう、みつめ、おうかん、ユニコーンの つの、いなずま しっぽ。野生ではまれ（6%）で、たまごの へんか で出やすい。
- **たまご**: 部品は それぞれ親のどちらかから。色は どちらかの親か、まぜた色。30% で部品が1つ別のものに かわり（めずらしい部品が出やすい）、そうでなければ 18% で まったく新しい色に。何代目かも記録（親より1代あと）。たまごの色と もようで、生まれる子の色が少しわかる。
- **名前**: 「ポ・ム・リン」のような音のかけら を3つほど つなげて自動でつける。日本語はカタカナ、英語はローマ字（Pomurin）。子どもは 親の名前の はじめと おわりを受けつぐ。自分で名前を変えることもできる（12文字まで）。

## ごはんで みためが かわる（v0.3）

なかよしに なった生きものに、ずかんから ごはんを あげられます。あげた ごはんの種類によって、見た目が すこしずつ かわっていきます。

- **あげかた**: ずかんで生きものをタップ → 「🍽 ごはんを あげる」の6つ（🍎🐟🌰🍯🍓🥕）をタップ。ごはんが とんでいって もぐもぐ食べます。すきな たべものだと「だいすきな ごはん！」と よろこびます（ずかんに すきなものも記録）。
- **おなか**: 6かい あげると「おなか いっぱい」。10分ごとに 1つ へって、また食べられます（一度に かわりすぎないように。また見に来る楽しみにも）。
- **なかよしに なるとき**にあげた ごはんも、かぞえて ひきつぎます。
- **かわりかた**（たくさん食べるほど ちかづく。6かいで 3わりほど、15かいで 6わりほど、40かいで ほぼ ぜんぶ）:

| ごはん | いろ | かたち・かざり |
|---|---|---|
| 🍎 りんご | あかく | ほっぺが まっかに、おおきく |
| 🐟 さかな | あおく | うろこもようと、つやつや ひかる すじ |
| 🌰 どんぐり | ちゃいろく | よこに まるまる |
| 🍯 はちみつ | きんいろ | ひとまわり おおきく、からだが ひかる、たくさん食べると きらきらが まわる |
| 🍓 いちご | ピンク | つぶつぶ（たべるほど ふえる） |
| 🥕 にんじん | オレンジ | せが たかく すらっと |

- いろいろ まぜて食べると、いろも まざります（りんご＋さかな で むらさきっぽく、など）。
- 3・8・15・25・40かい目で「✨ すこし かわった！」と きらきらが出ます。ずかんの くわしい画面に「たべたもの: 🍎5 🐟2」「かわってきた: 🍯 だいぶ きんいろに、おおきく」のように出ます。
- ずかんの一覧、たまごの画面、タイトルの生きものも、かわった見た目で出ます。
- たまごで生まれる子は、親の「生まれつきの見た目」を受けつぎます（ごはんで かわった分は受けつがない）。

## であったときの ごはん と 形の へんか（v0.4）

- **なかよしに なる前の ごはんは よく効く**: 1かいで ずかんの ごはん 8かいぶん。1〜2かいで 色も形も はっきり かわります。ふわっと 変わり、きらきらが出ます。
- **なかよしに なるか えらべる**: ハートが5つ たまっても すぐには なかよしに ならず、「💞 なかよしに なる」「👋 またね」を えらべます。そのあいだも ごはんで 見た目を かえられます（ハートは ふえない）。見た目が 気に入らなければ「またね」で わかれられます。
- **ぶひん（形）も かわる**: ごはんの きき目が 3わり半で 1つめ、6わり半で 2つめの ぶひんに かわります。であったときは 1かいで1つめ、2かいで2つめ。ずかんの ごはんでは 7かいほどで1つめ、16かいほどで2つめ。

| ごはん | 1つめ | 2つめ |
|---|---|---|
| 🍎 りんご | まんまるの からだ | ぺろり の くち |
| 🐟 さかな | さかなの しっぽ | ひれ |
| 🌰 どんぐり | ふわふわ しっぽ | くまみみ |
| 🍯 はちみつ | しょっかく | ようせいの はね |
| 🍓 いちご | しずくがたの からだ | ふたば |
| 🥕 にんじん | うさみみ | ちょこん しっぽ |

- からだの よこ・たて・大きさの かわりかたも 前より大きくした（どんぐり・にんじん・はちみつ）。
- ずかんの くわしい画面の ぶひん は「いまの見た目」の ぶひんを出します。ぶひん集め（ずかんの ぶひん タブ）と たまごの 受けつぎは、生まれつきの ぶひん のままです。

## ごはんで かわらない ことが あった のを 直した（v0.5）

- **原因**: 生まれつき その ごはんの ぶひん と 色を もっている 生きものは、ごはんを あげても ほとんど 見た目が かわらなかった。たとえば うみの 青い子（さかなの しっぽ・ひれ つき）に 🐟、ピンクの しずくがたの子に 🍓、赤い まんまるの子に 🍎。全部のすみかで 240ぴきずつ ためすと、であったときの ごはん1かいで 約3% が ほぼ かわらなかった。
- **直したこと**:
  - ごはんごとに ぶひんの こうほを 4つに ふやし、もう もっている ぶひんは とばして 次の ぶひんに かえる（3だんかい: きき目 3わり半・6わり半・9わり弱）。
  - もともと にた 色の 子は、もっと こく あざやかに（明るい子は こく、くらい子は 明るく）して ちがいを出す。色の かわりかたも 少し 強めた。
  - ずかんの ごはんは 1かいの きき目を 少し 強めた（4〜5かいで 1つめの 形、11かいほどで 2つめ）。形が かわったときは「✨ かたちが かわった！」と きらきらが出る（2・4・7・12・20・30かい目にも「すこし かわった」）。
- ためし: 6つの すみか × 40ぴき × 6つの ごはん で、であったときの ごはん1かいで 見た目が ほぼ かわらない子は 0 に なった。

| ごはん | ぶひんの こうほ（じゅんに） |
|---|---|
| 🍎 りんご | まんまる → ぺろり → ふたば → おなか もよう |
| 🐟 さかな | さかなの しっぽ → ひれ → おーっ の くち → しましま |
| 🌰 どんぐり | ふわふわ しっぽ → くまみみ → おおきな て → おもち がた |
| 🍯 はちみつ | しょっかく → ようせいの はね → しましま → キラキラ め |
| 🍓 いちご | しずくがた → ふたば → みずたま → にっこり |
| 🥕 にんじん | うさみみ → ちょこん しっぽ → 4ほん あし → ねこぐち |

## 場所ごとの音（v0.2）

音のファイルは使わず、ブラウザの中で その場で作っています。最初にどこかをタップすると鳴りはじめ、タイトルの「🔊 おと」で消せます。

| 場所 | ずっと鳴る音 | ときどき鳴る音 | ゆれる音 | あしおと |
|---|---|---|---|---|
| のはら | そよかぜ | ことり、ひばり、はち | はっぱ さわさわ | くさを ふむ |
| うみ | 海の中の ごーっ | あわ ぽこぽこ、とおくの くじら | あわ ぷくぷく | みずの なか |
| もり | 葉っぱの さわさわ、小川 | かっこう、きつつき、ことり | はっぱ さわさわ | くさを ふむ |
| ゆきやま | ひゅーっ という風 | ゆきの きらきら、ふきつける風 | ゆきが さらさら | さくっ |
| かざん | ごごご という地なり | ひのこ ぱちぱち、ようがん ぼこっ、ごろごろ | いしが ころころ | じゃりっ |
| よるのもり | よかぜ | こおろぎ、ふくろう、きのこの ちりん | きのこが ちりん | くさを ふむ |

ゆれる音は、ゆれはじめに1回と そのあと2秒ほどおきに小さく（1回のゆれで3回まで）。ふわっと大きくなって ふわっと消える音にしています。

タイトルと たまごの画面は のはらの音を小さく、なかよくなる画面は その場所の音を少し小さくして流します。

## 技術メモ

- 1つの HTML（`ikimono/index.html`）。外から読むのは `../common/kakin.js` だけ。画像・音声ファイルなし。
- 描画は Canvas 2D。`drawCreature(ctx, genome, x, y, R, state)` が生きもの1ぴきを描く（R はからだの半径）。部品ごとに `drawWings / drawTail / drawLegs / drawTop / drawPattern / drawFace`、からだの形は `bodyPath`、目や耳の位置は `bodyInfo`。state は `t`（時間）、`mood`（idle / shy / happy / eat）、`look`、`lift`、`flip` など。
- 景色は `drawBg`（空・遠くの山・中くらいの木・地面の飾り。`hash` で場所ごとに決まった並び）と `drawBush`、まわりの粒（あわ・ゆき・ひのこ・ほたる）は `drawAmb`。すみかの色は `SKY`、出やすい部品と色は `HABS[].w / hue / s / l`。
- 部品の定義は `PARTS`、めずらしい部品は `RARE`、その場所にしかいない部品は `EXCL`。部品を足すときは `PARTS` と描く関数と `TEXT.ja/en.part` の3か所。
- 野生の生きものは `wildGenome(hab)`、たまごは `mixGenome(A, B)`（へんか `mut` も返す）。
- 保存: localStorage `ikimono-book` = `{next, list:[{id, g, nm, cn, from, par, gen, fk, at, fd?, ful?}], seen:{cat:{部品:1}}}`。`fd` は ずかんで あげた ごはんの かいすう（6つの配列、v0.3〜、ないときは 0）、`fm` は であったときに あげた かいすう（v0.4〜、`MEET_W`=8 倍で効く。v0.3 で であったときの分は `fd` に入っている）、`ful` は おなか `{n, t}`（n こ たまっていて、t から 10分ごとに 1つ へる）。`g` が いでんし、`nm` は名前の音のかけら、`cn` は自分でつけた名前、`fk` は すきな たべものを知っているか。ほかに `ikimono-lang`、`ikimono-mute`、`ikimono-found`。
- 言語は ほかのゲームと同じ決め方（`?lang=` → 前回 → 入口ページ → ブラウザ）。文字は `TEXT`（ja / en）。
- 効果音は WebAudio で その場で作る（`sfx`）。最初のタップで音が出るようになる。
- まわりの音: `ambStart(id, vol)` が ずっと鳴る音（ノイズにフィルターとゆらぎ、`ambBed`）を用意し、`AMBEV[id]` の ときどき鳴る音を `ambTick()`（毎フレーム）が ランダムな間かくで鳴らす。場面が変わると `showScene` → `sceneAmb()` で切りかえ（フェード）。ゆれる音は `habRustle()`（やわらかい音は `softNoise`）、あしおとは `habStep()`（景色が120px動くごと）。画面が かくれると AudioContext を止める。

- アプリの準備（2026-11-19）: `manifest.webmanifest`（アプリの名札）、`app/` の仮アイコン、`app-files.json`（アプリとして開いたときに まとめて保存するファイルの一覧）、`<head>` に `common/app.js`（オフライン）と `common/hikkoshi.js`（games.hajimaruyo.com への記録の引っ越し）。ファイルを足したり変えたりしたら `node tools/make_app.cjs --no-icons` で一覧を作りなおす。くわしくは [app-plan.md](app-plan.md)。
- ごはんの見た目（v0.3）: `lookG(g, fd)` が もとの いでんし `g` から「いまの見た目」をつくる（キャッシュつき、`lookOf(e)`）。色は `DIET[i]` の色に むけて まぜる（色相は ベクトルで平均、量は `1 - exp(-n/15)`）。かたちと かざりは `g.dz = {blush, shine, plump, big, seeds, tall}`（ぶひんの おきかえは `DIET_PARTS`、見た目の かいすうは `effFd(e)`） を `drawCreature`（大きさ・よこ・たて）、`drawDiet`（うろこ・つや・つぶつぶ）、`drawFace`（ほっぺ）が読む。たまご（`mixGenome`）は もとの `e.g` を使う。ずかんの ごはん は `feedBook` / `renderDiet` / `tummy`。`makeLive` は ずかんの生きもの（e）を わたすと 見た目が その場で かわる。
- なきごえ（v0.6）: `cry(g, mood)`。`g.seed` の 乱数で 1ぴきごとに すこし ちがう。おねがい: `book.wish`（{cat,k}）、`book.wishDone`、`newWish()` は まだ みていない めずらしくない ぶひんから えらぶ。`addToBook` で かなったか しらべる。
