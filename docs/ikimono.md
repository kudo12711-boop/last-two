# ふしぎな いきもの ずかん（英語名 Curious Critters・仮）

最終更新: 2026-11-12 ／ いまの版: v0.1（試作、公開前）

## ひとことで

くさむらで ふしぎな生きものに出会い、たべものや なでなでで なかよしになって ずかんに集めるゲームです。2ひきを近づけると たまごが生まれ、両方の特徴をまぜた 世界に1ぴきだけの子どもが生まれます。生きものも景色も、絵のファイルを1枚も使わず、すべてプログラムで描いています。

## 遊び方（v0.1）

1. **すみかを えらぶ**: のはら・うみ・もり（むりょう）、ゆきやま・かざん・よるのもり（ぜんぶ版 🔒）。
2. **さがす**: 指で景色を左右にスワイプ（◀ ▶ ボタンや矢印キーでも）。ときどき くさむら（うみは海藻、かざんは岩、よるのもりは光るキノコ）が ゆれて ★ が光るので、タップすると生きものが飛び出します。
3. **なかよくなる**: 下の6つのたべもの（🍎🐟🌰🍯🍓🥕）をタップしてあげるか、生きものを指でなでます。ハートが5つたまると なかよし。生きものごとに「すきな たべもの」が1つあり、それをあげるとハート2つ（ずかんにも すきなものが記録される）。はじめは もじもじ（よそ見して ふるえる）していて、なかよくなると にこにこします。
4. **ずかん**: 「いきもの」タブで集めた生きもの（番号・名前・★めずらしい・🥚たまご生まれ）。タップすると大きく見られて、名前の変更、たまごへ が使えます。「ぶひん」タブで 見つけた部品の数（「なし」をのぞく 48こ中いくつ）と、まだ見つけていない部品の ？？？（その場所にしかいない部品は「よるのもりに いる」などのヒント）。
5. **たまご**（2ひき以上で使える）: 下のボタンで2ひきえらび、指で1ぴきを もう1ぴきに近づけると ハートが出て たまごが生まれます。たまごを3回トントンすると われて子どもが生まれます。

## 生きものの しくみ

- 8つの部品の組み合わせ: からだ7・もよう7・め6・くち6・あたま9・しっぽ7・あし5・はね5（「なし」もふくむ）。これに 色2つ（からだ・アクセント）、あざやかさ、明るさ、大きさ、すきな たべもの。組み合わせは 数十万とおり以上。
- **すみかごとに 出やすい部品と色**: うみ は うねうね足・さかなのしっぽ・ひれ・青系、もり は ふたば・はっぱしっぽ・緑や茶色、ゆきやま は ふわふわしっぽ・白っぽい色、かざん は つの・きば・とげとげ・赤系、よるのもり は ひかる め・こうもりの はね・むらさき系。
- **その場所にしか いない部品**: ひかる め（よるのもり）、うねうね足・さかなのしっぽ・ひれ（うみ）、こうもりの はね（よるのもり・かざん）、つの（かざん・ゆきやま）。ほかの場所では、たまごの へんか でしか出ません。
- **めずらしい部品 ★**: おほしさま・にじいろ もよう、みつめ、おうかん、ユニコーンの つの、いなずま しっぽ。野生ではまれ（6%）で、たまごの へんか で出やすい。
- **たまご**: 部品は それぞれ親のどちらかから。色は どちらかの親か、まぜた色。30% で部品が1つ別のものに かわり（めずらしい部品が出やすい）、そうでなければ 18% で まったく新しい色に。何代目かも記録（親より1代あと）。たまごの色と もようで、生まれる子の色が少しわかる。
- **名前**: 「ポ・ム・リン」のような音のかけら を3つほど つなげて自動でつける。日本語はカタカナ、英語はローマ字（Pomurin）。子どもは 親の名前の はじめと おわりを受けつぐ。自分で名前を変えることもできる（12文字まで）。

## 技術メモ

- 1つの HTML（`ikimono/index.html`）。外から読むのは `../common/kakin.js` だけ。画像・音声ファイルなし。
- 描画は Canvas 2D。`drawCreature(ctx, genome, x, y, R, state)` が生きもの1ぴきを描く（R はからだの半径）。部品ごとに `drawWings / drawTail / drawLegs / drawTop / drawPattern / drawFace`、からだの形は `bodyPath`、目や耳の位置は `bodyInfo`。state は `t`（時間）、`mood`（idle / shy / happy / eat）、`look`、`lift`、`flip` など。
- 景色は `drawBg`（空・遠くの山・中くらいの木・地面の飾り。`hash` で場所ごとに決まった並び）と `drawBush`、まわりの粒（あわ・ゆき・ひのこ・ほたる）は `drawAmb`。すみかの色は `SKY`、出やすい部品と色は `HABS[].w / hue / s / l`。
- 部品の定義は `PARTS`、めずらしい部品は `RARE`、その場所にしかいない部品は `EXCL`。部品を足すときは `PARTS` と描く関数と `TEXT.ja/en.part` の3か所。
- 野生の生きものは `wildGenome(hab)`、たまごは `mixGenome(A, B)`（へんか `mut` も返す）。
- 保存: localStorage `ikimono-book` = `{next, list:[{id, g, nm, cn, from, par, gen, fk, at}], seen:{cat:{部品:1}}}`。`g` が いでんし、`nm` は名前の音のかけら、`cn` は自分でつけた名前、`fk` は すきな たべものを知っているか。ほかに `ikimono-lang`、`ikimono-mute`、`ikimono-found`。
- 言語は ほかのゲームと同じ決め方（`?lang=` → 前回 → 入口ページ → ブラウザ）。文字は `TEXT`（ja / en）。
- 効果音は WebAudio で その場で作る（`sfx`）。最初のタップで音が出るようになる。
