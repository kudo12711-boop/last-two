## v0.1 の中身

ホームに 大きなボタンが 3つ（🧱 つみき たおし／🦛 ぱくぱく どうぶつ／🎈 ふうせん わり）と、ボールえらび。

- **なげかた**: 画面の下の ボールを 指で 上に シュッと はじく。はやく はじくほど 遠くへ、ななめに はじくと 左右へ とぶ。ゆっくり 長く 押し上げても やさしく とぶ（小さい子むけ）。指を 画面の 上の ほうまで もっていくと その場で なげる。ボールは つぎつぎ なげられる（0.35びょうで 次の ボールが 出る）。
- **ねらいの おてつだい**（おうちのかた で えらぶ）: つよい（さいしょ）／すこし／なし。だいたい ねらった ものの ほうへ ボールを まげてくれる。
- **ヒント**: 8びょう なげないと 👆 と 声で 教える。2回 つづけて 手前に 落ちると「もっと つよく」、2回 とびこえると「そっと」と 教える。
1. **つみき たおし**: 机の上に どうぶつの 顔の つみき（ねこ・くま・うさぎ・ぶた・かえる・ひよこ）。当たると とんで、上の つみきも くずれおちる。ぜんぶ たおすと クリア。ステージ 1〜8 は 手で 作った ならべかた、9 から先は 番号ごとに きまった ランダム。
2. **ぱくぱく どうぶつ**: かば・くま・かえる・ぶた・ライオン・ねこ が 口を あけて まっている。口に 入ると もぐもぐ。頭の上の ○ が おなかの のこり。ぜんぶ おなか いっぱいで クリア。ステージが 進むと 左右に うごく・口を とじたり あけたり する。
3. **ふうせん わり**: 下から ふうせんが うかんでくる。当てると パン！ きらきらの ふうせん（金色、10％）は 3こ ぶん。きまった 数を わると クリア。進むほど 数が ふえ、はやく・小さく なる。
- クリアで 紙ふぶき・声。「もういちど」「つぎへ ▶」。遊んでいる 間も「◀ まえ」「つぎへ ▶」（クリアした ところまで）で 行き来できる。ホームの ボタンは さいごに 遊んだ ステージから はじまる。
- ボール 7しゅるい: あか・ビーチ・テニス（むりょう）、サッカー・ほし（きらきらが 出る）・にじいろ（にじの あと）・すいか（ぜんぶ版）。

## 技術メモ

- ファイル: `try-ed3c16d137084dd7/index.html`（1ファイル、canvas に 描く）＋ `voice/<声>/<key>.mp3`。`../common/kakin.js` を読む。コピーは `/mnt/project-files/pon/`。
- 小さな 3D: カメラは (0, 1.1, 0) から +z を 見る。点 (x, y, z) は 画面の (W/2 + x·FOC/z, HOR + (1.1 − y)·FOC/z)。HOR = 画面の 高さの 34%。手の ボールは z = 1.15。じゅうりょく 7.5、ボールの 半径 0.13。遠い じゅんに 描く（机は うしろの はし、ほかは z で ならべる）。
- なげる: 指の さいごの 0.13びょうの 速さ（画面の 高さ／びょう）から、前への 速さ = 1.6 + 上むきの 速さ × 0.9（2〜8.5）、上への 速さ = 前への 速さ × 0.6、左右の 向きは 指の 向き × 0.85。
- おてつだい（`assist`）: まと ごとに「同じ 角度で なげて ちょうど 当たる 速さと 向き」を 計算し（うごく まとは とどく 時間ぶん 先を ねらう）、指の なげかたに いちばん 近い まとへ よせる（つよい 0.88／すこし 0.55）。
- つみき: 1こ 0.34 の 四角。当たり判定は 回転を 無視した 箱。とんでいる つみきが とまっている つみきに ふれると それも とぶ。下の つみき（`sup`）が うごくと 上の つみきも 落ちる。机の 上か 地面で とまる。
- 食べもの（v0.2）: `FOODS` と `drawFood`。`drawBallK` は 食べものの 名前なら drawFood を よぶ。手の 食べものは `HD.food`。動物は 食べたものを `a.ate` に おぼえる。
- つみきの れんさ（v0.2）: ボールが 新しい つみきに 当たると 速さは 0.9ばい、はねかえりは 0.35 だけ。とんでいる つみきは となり（1こぶん）まで ふれれば たおす。1球で たおした 数は `G.wk`。
- ふうせんの れんさ（v0.2）: `MF.pop` で 割れると、(半径＋半径)×1.75 より ちかい ふうせんが 0.09〜0.14びょう後に 割れる。つづけて 割れた 数は `G.combo`（0.7びょう いないなら つづき）。
- ぱくぱく: 頭の 前の 面を ボールが 通りすぎた 位置で、口の だえんの 中なら たべる、頭や からだなら はねかえる。
- 記録: localStorage `pon-v1`（lang, voice, snd, aim, ball, best＝ステージの 行ける ところ, cur＝さいごの ステージ, thrown）。
- テスト用: `?test=1` で `window.__pon`（`loadStage(m,n)`、`throwBall(よこ, うえ)`、`stageClear()` など。m は t／p／f）。
- 声: 日本語は VOICEVOX（台本 `/mnt/project-files/voice-ja/build_lines.py` の `G['pon']`、作るのは `make_voicevox.py pon <リポジトリ>/try-ed3c16d137084dd7/voice`）。英語は Kokoro（`/mnt/project-files/pon/tools/make_voice.py`、台本は index.html の `//@@LINES-BEGIN`〜`END` を node で JSON にした `lines.json`）。index.html の LINES.ja は 端末の声 用で、台本と 同じ 漢字まじりの 文。[voice-ja.md](voice-ja.md)
- アプリの準備: `tools/apps.json` に 追加済み（アイコンは 仮の 🎯）。ファイルを 変えたら `node tools/make_app.cjs --no-icons` で `app-files.json` を 作りなおす。
