# もよう・背景メーカー（英語名 Backdrop Maker・仮）

最終更新: 2026-11-12 ／ いまの版: v0.1（ブラウザ版の試作、2026-11-12）

## ひとことで

AI を使わず、プログラムがその場で描く背景と模様を、何枚でも無料で作って保存できる道具です。ゲームではなく「実用ツール」の1つめ。将来は Canva や Figma の中で使える追加機能（プラグイン）にする予定です。

- ファイル: リポジトリの `moyou/index.html` と `moyou/engine.js`（コピーは `/mnt/project-files/moyou/`）

## 使い方（v0.1）

1. **しゅるい** を選ぶ（11種類）: なみ、くも、やまなみ、ほしぞら、グラデーション、ひかりの つぶ、つぶつぶ、みずたま、しましま、かたち、そらと けしき。小さな見本は、いま選んでいる色で描かれます。
2. **いろ** を選ぶ（12組: パステル、うみ、ゆうやけ、もり、よぞら、モノクロ、ビビッド、くすみ、さくら、ネオン、こはく、ミント）。下の5つの色の四角を押すと、1色ずつ自由に変えられます。
3. **ちょうせい**: こさ・数、大きさ、やわらかさ、ざらざら（フィルムのような粒）。
4. **つなぎ目なし**（なみ・やまなみは横だけ、ほかは縦横）: ならべても切れ目が出ない画像になります。「4まい ならべて 見る」で確かめられます。グラデーションと そらと けしき は対象外。
5. **🎲 べつの形** で同じ設定のまま形だけ変わります。**↶ もどる** で前の状態へ（50回まで）。
6. **保存する大きさ**: Instagram 正方形、ストーリー、X ヘッダー、YouTube サムネイル、スライド 16:9、パソコンの壁紙（フルHD・4K）、この画面の壁紙、A4 印刷（よこ・たて、300dpi）、自分で決める（16〜8000px）。
7. **画像を保存**（PNG）、**コピー**（そのまま Canva や PowerPoint に貼りつけられる）、**設定のリンクをコピー**（同じ絵をあとで作り直せる URL）。
- **そらと けしき** を選ぶと、時刻（0:00〜23:45）、天気（はれ・くもり・あめ・ゆき・きり・あらし）、けしき（やま・うみ・おか・まち・そらだけ）を選べます。

## 技術メモ

- `moyou/engine.js` が描く部品（`window.Backdrop`）。`Backdrop.render(canvas, opts)` で canvas いっぱいに描く。`opts` は `type, palette(5色), seed, density, scale, soft, grain(0〜1), tile` と、そら用の `hour, weather, land`。
- 大きさに関係なく同じ絵になるよう、長さはすべて `S = √(幅×高さ) / 1000` を単位にし、乱数（`rng(seed)`、mulberry32）の使う順番も大きさで変えない。数（雲や点の数）も大きさで変えない。
- つなぎ目なし: 点や形は `wrap()` で反対側にも描く。なみは sin の周期を幅の整数分の1に、やまなみは両はしが同じ高さになる でこぼこ（`ridge()`）。しましまは つなぎ目なしのとき 0°（横）か 90°（たて）だけにして、幅で割り切れるよう しまの太さを調整。
- ぼかしは `ctx.filter` を使わない（古い Safari で動かないため）。かわりに `shadowBlur` とグラデーションを使う。
- ざらざらは最後に `getImageData` で全部の点に明るさのゆらぎを足す。
- そら: 時刻ごとの空の色の表 `SKY_KEYS`（上の色・地平線の色・明るさ）を線でつないで使う（`skyAt(hour)`）。天気ごとの 灰色の量・雲の数・雲の暗さは `WEATHER`。太陽は 5:48〜18:48 に弧を描き、月は 18:30 からの11時間。けしきは `drawLand()`。
- しゅるいの一覧は `Backdrop.TYPES`、色の組は `Backdrop.PALETTES`（ja / en の名前つき）。しゅるいを足すときは関数を書いて `TYPES` に1行足す。
- ページ（`moyou/index.html`）: 設定は URL の `#` 以降に入る（例 `#t=waves&p=e8f6fb-…&s=123&d=50…`）。コピーは `ClipboardItem` に Promise を渡す（Safari 対策）。言語は `?lang=` → ブラウザの言語。
- **そらタブも同じ engine.js を使う**。engine.js を直したら `sh sora-tab/build.sh` でコピーと zip 作り直し。
