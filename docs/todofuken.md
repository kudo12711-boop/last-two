# 都道府県パズル

最終更新: 2026-11-03 ／ いまの版: v0.3（課金のしくみ入り・公開前）

## ひとことで

47都道府県の本物の形のピースを、指で日本地図の正しい場所にはめるパズルです。はまると名前を読み上げて名物を見せてくれます。

## 遊び方（いまの版）

### こども ステージ（v0.2 で追加、4さいくらいから）

- ホームのいちばん上に、となりどうしの県を3〜5まいずつにわけた12このステージ（きたの くに、かんとう その1 …）。地図が大きく映るので、スマホでも遊びやすい。
- ピースはひらがなを大きく、漢字は小さく。持ち上げたピースも大きめに表示。
- 当たりの範囲がふつうより広い。正しい場所に近づくと、その場所が黄色く光って「いま放していいよ」がわかる。
- まちがえると、やさしい音と「おしい！」。1回で正しい場所が光り、3回まちがえるとピースが自分で正しい場所へ飛んでいく（「ここだよ」）。
- はまると「やったね！ あおもりけん」のようにほめて読み上げ、地図の上に名物の絵（🍎など）が残る。タイマーと星はなし。
- ステージをクリアすると「シール ゲット！」。ステージのボタンには集めた名物の絵と ✓ がつく。
- **シールずかん**: どのモードでも、はめた県の名物シールがたまる（47まい）。シールをタップすると名前と名物を読み上げ。まだの県はかげの形とよみがなだけ。
- こどもステージでは、シールを持っている県がまわりの地図にうすく色づくので、進みぐあいが見える。

### ちほう・ぜんこく（v0.1 から）

- 「ぜんこく（47まい）」か、地方ごと（6地方、7〜9まい）を選ぶ。スマホでは地方ごとが遊びやすい。
- ピースには漢字とふりがな。だいたいの場所で放せばぴたっとはまる。はまると読み上げ＋「青森県 🍎 りんご」のような名物。はめた県をタップするともう一度見られる。
- 同じピースを2回まちがえるか 💡 で、正しい場所がピカピカ光る。
- クリアで★3つまでの評価とタイム、自己ベストを記録。
- 「さかいせん」「なまえ」を消すとむずかしいモード。「こえ」「おと」も切りかえ可能。
- 沖縄は本当の位置だと地図が小さくなるので、左上の点線の四角に置いている（九州・沖縄モードでは鹿児島の左）。

## 技術メモ

- `tools/src.html` を直してから、`python3 tools/build.py tools/shapes.json` を実行すると、`todofuken.html`（Artifact 用）と `index.html`（Pages 用、`<!doctype>` などを足したもの）ができる。index.html をリポジトリの `todofuken/index.html` にコピー。
- 形データ: dataofjapan/land の japan.geojson を mapshaper で3%に簡略化（`tools/japan-simplified.geojson`）。`tools/build_shapes.py` が遠い島（伊豆・小笠原、奄美、先島）を落とし、沖縄を囲みに移して `shapes.json` を作る。
- こどもステージは `KIDS`（`s1`〜`s12`）。九州・沖縄と ステージ12 は `okiLocal` で沖縄を鹿児島の左に置く。
- 保存: localStorage `todofuken-best`（タイム・星）、`todofuken-stickers`（シールの県番号）、`todofuken-kid`（クリアしたステージ）。v0.1 の src は `tools/src-v0.1.html`。読み上げはブラウザの speechSynthesis。
- 課金: `<script src="../common/kakin.js">` を ゲームの script の前に読み、`Kakin.setup({game: 'todofuken', ...})`。🔒は `.kk-lock` クラス、さわったら `Kakin.ask()`、ぜんぶ版かどうかは `Kakin.full()`。むりょうの範囲は `FREE_MODES`（`s1`〜`s4` `hk` `kt`）。`startGame` の はじめで止めるので、地図のタップや「つぎの ステージへ」も 同じように🔒になる。お店のボタンはホームの下の `#kkSlot`。
