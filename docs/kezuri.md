# けずって なにかな？（幼児向けスクラッチ）

最終更新: 2026-11-03 ／ いまの版: v0.1（公開済み）

## ひとことで

銀色のスクラッチを指でけずると、下にかくれた絵が少しずつ見えてきます。「なにかな？」と出てくる絵の中から当てると全部が見えて、声で名前を教えてくれます。見つけたものは「ずかん」に集まっていきます。

## 遊び方（いまの版）

- タイトルの「？」カードは、さわるとその場でけずれる「おためし」。
- 「はじめる」でカードが1まい出る。指でけずると、けずりカスが飛び、シャリシャリ音（指の速さで大きさが変わる）。
- 絵の場所と大きさは毎回すこしずつずれるので、どこにいるか探す楽しさがある。8秒さわらないと、まだけずっていない絵の上が光って「ここを けずってみて！」。💡ボタンでもいつでも出せる。
- むずかしさ（4段階）
  - ★ けずるだけ（2さい〜）: 絵が半分ほど見えたら自動で全部出て、名前を言う。
  - ★★ 2つから（3さい〜）: 絵が3割ほど見えたら、ちがう仲間の絵（例: きりん と にんじん）との2択。
  - ★★★ 3つから（4さい〜）: 2割ほどで3択。
  - ★★★★ 4つから（5さい〜）: 最初から4択。しかも同じ仲間どうし（例: どうぶつ4つ）なので、少しけずって当てる遊びになる。
- まちがえると、その絵がうすくなって「ちがうみたい。もうすこし けずってみよう！」。当たると「あたり！」→ 名前 → 紙ふぶき。
- テーマ: ぜんぶ／どうぶつ16／のりもの14／たべもの14／うみ12／しぜん14（全70）＋ おうち（写真）。
- ずかん: 見つけたものは色つき、まだのものは黒いかげ（形だけ見える）。初めてのときは「NEW!」と「ずかんに はいったよ！」。2回目からは ×2 など回数。ずかんで絵を押すと名前を言う。仲間を全部集めるとタブに👑と「ぜんぶ あつめたね！」。
- きらきら: 8回に1回くらい、金色に光る「きらきら」版が出る。ずかんにも✨がつく（何度も遊びたくなる仕掛け）。
- まだ見つけていないものが出やすく、直前に出たものは続けて出ない。
- おうちの しゃしん: おうちの人が写真を選び、名前を入れ、🎙️で自分の声で名前を録音できる。「おうち」テーマで写真がスクラッチの下にかくれ、当てると録音した声で呼ぶ（録音がなければ端末の読み上げ）。写真と声はその端末の中だけに保存。
- せってい: 声（AIのこえ1〜4／端末の声／なし）、音、ことば（日本語／English）、ずかんリセット。

## これから

- 実際に子どもに遊んでもらって、けずりやすさ（指の太さ）、答えが出るまでの量、声の量を調整。
- 絵文字ではなく描いた絵にすると、もっとかわいく、端末による見た目の差もなくなる。
- 仲間をふやす（虫、きょうりゅう、おしごと など）、季節のテーマ。
- 英語の AI 音声（いまは英語のときは端末の読み上げ）。

## 技術メモ

- リポジトリ `kezuri/index.html`（1ファイル）＋ `kezuri/voice/<声>/<key>.mp3`。key: `start0/1` `q0/1` `ok0–2` `miss0/1` `new0` `shiny0` `comp0` `hint0` と、絵ごとの `it_<id>`（名前）。AI の声は日本語だけ。英語のときは端末の読み上げ（`tts`）。
- 文字は `TEXT`（ja/en の辞書）、絵は `CATS`（`[id, 絵文字, 日本語名, 英語名]`）。言語を足すときは TEXT に1つ足し、CATS の名前を足す。言語の決め方: `?lang=` → 前回選んだもの（`kezuri-lang`）→ 入口ページで選んだもの（`games-lang`）→ ブラウザの言語（日本語以外は英語）。
- スクラッチ: カードはキャンバス1枚。下に絵を描き、その上に「まく」（別のキャンバス）を重ねる。けずると まくを `destination-out` で消す。どれだけ見えたかは 40×40 のます目で数え、絵の部分（絵の中心から半径 0.4×大きさ）のうち何割けずったかで答えを出す（`LV[].th`）。画面の向きが変わったら、ます目から まくを作り直す。
- けずる音: ノイズをループで流し続け、指の速さで音量と高さを変える（`scratchSound`）。
- 保存（localStorage）: `kezuri-book`（絵ごとの `{n:回数, s:きらきら回数}`）、`kezuri-lv` `kezuri-cat` `kezuri-voice` `kezuri-sound` `kezuri-lang`。写真は IndexedDB `kezuri`（ストア `photo`、キー `p…`、`{name, blob(長辺900pxのJPEG), rec(録音), t}`）。
- 声の作り方は [まちがいさがし](machigai.md) などと同じ（Kokoro fp16 で候補を作り、whisper-tiny で聞き取って一番合うものを選ぶ）。名前だけの短い声（いぬ、ピザ など）は聞き取りにくかったので、合わなかった約50こは「○○だよ！」「○○だね！」「これは、○○！」の形でも作って、一番合うものを選んだ（slots2.json, cand2.py, asr2.mjs）。全332こが一致。道具は `/mnt/project-files/kezuri/tools/`（setup.sh＝道具の入れ方, slots.json＝セリフ一覧, cand.py, asr.mjs, pick.py）。
