# けずって なにかな？（幼児向けスクラッチ）

最終更新: 2026-11-23 ／ いまの版: v0.6（公開済み）

## ひとことで

銀色のスクラッチを指でけずると、下にかくれた絵が少しずつ見えてきます。「なにかな？」と出てくる絵の中から当てると全部が見えて、声で名前を教えてくれます。見つけたものは「ずかん」に集まっていきます。

## 遊ぶ場所

- 入口ページ「あそびのいりぐち」にもカードがあります。
- ファイル: `/mnt/project-files/kezuri/index.html`（声は `voice/`、声を作る道具は `tools/`）

## 遊び方（いまの版）

- タイトルの「？」カードは、さわるとその場でけずれる「おためし」。
- 「はじめる」でカードが1まい出る。指でけずると、けずりカスが飛び、シャリシャリ音（指の速さで大きさが変わる）。
- 絵の場所と大きさは毎回すこしずつずれるので、どこにいるか探す楽しさがある。8秒さわらないと、まだけずっていない絵の上が光って「ここを けずってみて！」。💡ボタンでもいつでも出せる。
- むずかしさ（4段階）
  - ★ けずるだけ（2さい〜）: 絵が半分ほど見えたら自動で全部出て、名前を言う。
  - ★★ 2つから（3さい〜）: 絵が3割ほど見えたら、ちがう仲間の絵（例: きりん と にんじん）との2択。
  - ★★★ 3つから（4さい〜）: 2割ほどで3択。
  - ★★★★ 4つから（5さい〜）: 最初から4択。しかも同じ仲間どうし（例: どうぶつ4つ）なので、少しけずって当てる遊びになる。
- まちがえると、その絵がうすくなって「ちがうみたい。もうすこし けずってみよう！」。当たると「あたり！」→ 名前 → 紙ふぶき。
- テーマ: ぜんぶ／どうぶつ16／のりもの14／たべもの14／うみ12／しぜん14（全70）＋ おうち（写真）。
- ずかん: 見つけたものは色つき、まだのものは黒いかげ（形だけ見える）。初めてのときは「NEW!」と「ずかんに はいったよ！」。2回目からは ×2 など回数。ずかんで絵を押すと名前を言う。仲間を全部集めるとタブに👑と「ぜんぶ あつめたね！」。
- きらきら: 8回に1回くらい、金色に光る「きらきら」版が出る。ずかんにも✨がつく（何度も遊びたくなる仕掛け）。
- まだ見つけていないものが出やすく、直前に出たものは続けて出ない。
- おうちの しゃしん: おうちの人が写真を選び、名前を入れ、🎙️で自分の声で名前を録音できる。「おうち」テーマで写真がスクラッチの下にかくれ、当てると録音した声で呼ぶ（録音がなければ端末の読み上げ）。写真と声はその端末の中だけに保存。
- けずる ふとさ（v0.2）: タイトルで ほそい／ふつう／ふとい／とても ふとい の4段階から選べる。上の「？」カードですぐ試せて、選んだ太さは次回も覚えている。小さい子は「ふとい」以上だとけずりやすい。
- また かくれる モード（v0.3）: タイトルの「けずった ところが また かくれる」で 🚫かくれない／🐢ゆっくり／🐇はやい を選べる。けずった所が時間とともに じわっと元の銀色にもどるので、急いでけずったり、両手や何人かでけずったりする遊びになる。「？」のおためしカードでも試せる。選んだものは次回も覚えている。
  - ⚡すぐ（v0.5）: けずった そばから、ほぼすぐに もどる（指の通ったあとが 一瞬だけ見える）。見えている量では答えまで届かないので、「すぐ」だけは「一度でも けずった所」の量で答えが出る。ちらっと見えた形から当てる遊び。
- せってい: 声（AIのこえ1〜4／端末の声／なし）、音、ことば（日本語／English）、ずかんリセット。

## 技術メモ

- リポジトリ `kezuri/index.html`（1ファイル）＋ `kezuri/voice/<声>/<key>.mp3`。key: `start0/1` `q0/1` `ok0–2` `miss0/1` `new0` `shiny0` `comp0` `hint0` と、絵ごとの `it_<id>`（名前）。AI の声は日本語だけ。英語のときは端末の読み上げ（`tts`）。
- 文字は `TEXT`（ja/en の辞書）、絵は `CATS`（`[id, 絵文字, 日本語名, 英語名]`）。言語を足すときは TEXT に1つ足し、CATS の名前を足す。言語の決め方: `?lang=` → 前回選んだもの（`kezuri-lang`）→ 入口ページで選んだもの（`games-lang`）→ ブラウザの言語（日本語以外は英語）。
- スクラッチ: カードはキャンバス1枚。下に絵を描き、その上に「まく」（別のキャンバス）を重ねる。けずると まくを `destination-out` で消す。どれだけ見えたかは 40×40 のます目で数え、絵の部分（絵の中心から半径 0.4×大きさ）のうち何割けずったかで答えを出す（`LV[].th`）。画面の向きが変わったら、ます目から まくを作り直す。
- けずる太さ: `FAT`（カードの幅に対する半径 0.045／0.075／0.11／0.16）、localStorage `kezuri-fat`（0〜3、はじめは1＝ふつう）。
- また かくれる: けずる前の まくを `covBase` にとっておき、0.15秒ごとに うすく重ねて元にもどす（毎フレームだと うすすぎて色が残るため）。ます目も同じ割合で 0 に近づけるので、答えが出るかどうかも「いま見えている量」で決まる。はやさ `BACK`（1秒あたり 0／0.5／1.2／4）、localStorage `kezuri-back`（0〜3、はじめは0）。`BACK` が `BACK_SEEN`（3）以上（＝すぐ）のときは、重ねる間かくを 0.05秒にし（`backStep()`、0.15秒だと ぱっぱっと もどって見えるため）、答え・ヒントの判定は ます目 `st.grid` ではなく「一度でも けずった所」`st.seen` を使う（`doneArr()`）。
- けずる音: ノイズをループで流し続け、指の速さで音量と高さを変える（`scratchSound`）。
- 保存（localStorage）: `kezuri-book`（絵ごとの `{n:回数, s:きらきら回数}`）、`kezuri-lv` `kezuri-cat` `kezuri-voice` `kezuri-sound` `kezuri-lang`。写真は IndexedDB `kezuri`（ストア `photo`、キー `p…`、`{name, blob(長辺900pxのJPEG), rec(録音), t}`）。
- 声の作り方は [まちがいさがし](machigai.md) などと同じ（Kokoro fp16 で候補を作り、whisper-tiny で聞き取って一番合うものを選ぶ）。名前だけの短い声（いぬ、ピザ など）は聞き取りにくかったので、合わなかった約50こは「○○だよ！」「○○だね！」「これは、○○！」の形でも作って、一番合うものを選んだ（slots2.json, cand2.py, asr2.mjs）。全332こが一致。道具は `/mnt/project-files/kezuri/tools/`（setup.sh＝道具の入れ方, slots.json＝セリフ一覧, cand.py, asr.mjs, pick.py）。
- 課金: `<script src="../common/kakin.js">` を ゲームの script の前に読み、`Kakin.setup({game: 'kezuri', ...})`。🔒は `.kk-lock` クラス、さわったら `Kakin.ask()`、ぜんぶ版かどうかは `Kakin.full()`。むりょうの範囲は `FREE_CATS`（`ani` `food`）。「ぜんぶ」テーマ（pool）は 遊べる仲間だけから出す。2択などの「はずれ」には 🔒の仲間の絵も出ることがある。お店のボタンは せってい画面の `#kkSlot`。
- 英語の AI の声（2026-11-11）: `voice/<af_heart|af_bella|bf_emma|am_michael>/<key>.mp3`（say の key と `it_<id>`）。声の設定は `ai:1`〜`ai:4`。作り方は `/mnt/project-files/i18n/tools/en_voice.py`。
- 声の順番待ち（2026-11-16）: 声はすべて `vqAdd()` の順番待ち（`VQ`）を通す。前の声を止めずに、終わったら次を鳴らす（AudioBuffer の `onended`、読み上げの `onend`、念のための時間切れ `max`）。`mode` なし＝待つ、`'idle'`＝ほかの声が鳴っていなければだけ（おしゃべり）、`'swap'`＝`'swap'` どうしだけ入れかわる（数を数える声・タップで名前）。`tag` で同じ種類の声が積み重ならないようにする（`vqHas()`）。止めるのは `hush()` だけ（画面を出るとき・音を消すとき・声のためし・録音の再生）。同じしくみは [ひらがな あそび](hiragana.md)・[ちいさな おうこく](oukoku.md) でも使っている。

- アプリの準備（2026-11-19）: `manifest.webmanifest`（アプリの名札）、`app/` の仮アイコン、`app-files.json`（アプリとして開いたときに まとめて保存するファイルの一覧）、`<head>` に `common/app.js`（オフライン）と `common/hikkoshi.js`（games.hajimaruyo.com への記録の引っ越し）。ファイルを足したり変えたりしたら `node tools/make_app.cjs --no-icons` で一覧を作りなおす。くわしくは [app-plan.md](app-plan.md)。

- 日本語の声（2026-11-23〜）: VOICEVOX。台本は `/mnt/project-files/voice-ja/build_lines.py`、作るのは `make_voicevox.py`。フォルダは `voice/vv_himari|vv_metan|vv_zunda|vv_hau/`（AIのこえ 1〜4。前の Kokoro の jf_* は消した）。きまり・クレジット・作り方は [voice-ja.md](voice-ja.md)。
