# チェイン・ノード

最終更新: 2026-10-25 ／ いまの版: v0.4

## ひとことで

ババ抜きの「しばらく膠着して、あるとき一気にペアがそろう」気持ちよさを、CPU 3体とのリアルタイム対戦（30〜60秒）にしたゲームです。電子回路のような見た目です。

- 2026-10-22、くどうさんが他のAI（Gemini）との会話のスクショを見せて「このようなゲームを作りたい」と依頼。スクショには2つの案があり、そのうちの1つがこの「チェイン・ノード」でした（もう1つは [雪だるまパニック](yukidaruma.md)）。

## 技術メモ

- 1ファイルの HTML（外部ライブラリなし）。ビルド手順はありません。直接編集して、同じパスで Artifact を再公開します。
- 自己ベストはブラウザの localStorage に保存。
- ルール（v0.4）: プールから引いて手札とペアになれば消える。ペア4組ごとに連鎖レベル+1（最大4）。ペアを取ったマスの周囲をレベル数だけ表にし、表向き同士の同じ数字は自動で消えて連鎖。ババは誰ともペアにならず、最後に持っていると −50 点、プールに戻すときも裏向き。
