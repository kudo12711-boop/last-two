# ぬけぬけリング

最終更新: 2026-10-25 ／ いまの版: v0.6

## ひとことで

1人で遊ぶ連鎖パズルです。輪になった5つの手札がすべて見えていて、1枚を隣へ渡すとペアが消え、消えた手札がまた次へ1枚渡し…と、ぷよぷよのように連鎖します。

## 遊び方（いまの版）

- カードをタップすると、矢印の先の手札の一番うしろに入ります。そこに同じ数字があれば2枚とも消えます。
- 消えた手札は、一番左の札（「先頭」）を自動で次の手札に渡します。またそろえば消えて…と連鎖が続きます。
- 決められた手数のうちに全部消せばクリア。★は「全部消す」「目標の連鎖を起こす」「ヒントを使わない」の3つ。

**仕掛け（ワールドごとに増える）**

| 名前 | 出てくる所 | 中身 |
|---|---|---|
| ババ | ワールド2〜 | そろわない札。先頭に来るとそこで連鎖が止まる。クリア時に残っていてもよい |
| カギの手札 | ワールド3〜 | 点線の手札。タップできず、連鎖でしか札が出ていかない |
| こおり札 | ワールド4〜 | しましまの札。タップもペアもできない。同じ手札でペアが消えるととける |
| もどり札 | ワールド5〜 | 紫のふち。タップすると逆向き（ひとつ前の手札）へ渡る |
| いかり札 | ワールド6〜 | 太いふち。先頭でも送り出されず、そこで連鎖が止まる |

「つめぬけ」は Claude がつけた名前で、詰め将棋＋「ぬけ」。2〜4手ぴったりで全部消す問題で、正しい1手目はひとつだけです。

## 技術メモ

- 1ファイルの HTML。ステージのデータは HTML の中に埋め込み。直接編集して同じパスで Artifact を再公開します。
- 保存キーは localStorage の `nkr3_` で始まるもの。ステージ id は `s0`…（本編）、`t0`…（つめぬけ）、`daily`、`vip`（パスの特別ステージ）、`u1`〜`u5`（練習面、0始まりのワールド番号に対応）。
- カードの書き方: 数字 ＋ 100×フラグ（1=こおり、2=いかり、4=もどり）、0=ババ。ステージ形式は `[手札, カギの手札, 手数上限, 連鎖目標]`。
- ステージ生成: `/mnt/project-files/nukenuke-ring/tools/`（engine.js, worlds.js, build.js, tsume.js）。`sh run.sh` で全ワールドを並列に作り `levels-packed.json` にまとめ、それを HTML に入れます。ビーム探索で解を探し、6ペア以下は総当たり。ステージ1-1だけは手作り。
- 注意: 乱数は `Math.imul` を使うこと（ふつうの掛け算だと精度が落ちてループする）。
- 今日のステージはブラウザの中で日付から作ります。ヒントはページ内のソルバーで次の一手を探します。
