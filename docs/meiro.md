# ゆびで めいろ（幼児向け）

最終更新: 2026-11-09 ／ いまの版: v0.3（公開済み）

## ひとことで

画面の迷路を指でなぞって、キャラクターをゴールまで連れていく幼児向けゲームです。かべにぶつかっても失敗にならず、やさしい声で応援してくれます。

2026-10-25、くどうさん「幼児用のゲームで、画面に表示された迷路を指でなぞって解くというものを作りましょう」。

## 遊び方（いまの版）

- キャラを選ぶ（「🎲 おまかせ」を押すと、迷路ごとにキャラがランダムで決まる）: 🐶→🏠、🐰→🥕、🐧→🐟、🐝→🌻、🚀→🌙、🚗→🏁。
- キャラに指をあててなぞると、道にそってついてくる。かべは通りぬけられず、ぶつかると「ぽよん」とゆれるだけ。
- 指をはなしても、キャラかなぞった線のどこからでも続きができる。逆になぞれば戻れる。
- 道のとちゅうのアイテム（🦴や🍓）を集めてゴールすると、紙ふぶきとシール1まい。
- むずかしさ ★〜★★★★（2〜5さい向け）。迷路は毎回自動で作る。
- 「みちしるべ」（ゴールまでの道にうすい点、最初はオン）、💡 で道がピカピカ光る。
- 声は [まちがいさがし](machigai.md) と同じ AI の声（4種類×14セリフ。「ゴールまで なぞってね」「もうすこし！」「ゴール！やったね！」など）。

## 技術メモ

- リポジトリ `meiro/index.html`（1ファイル）＋ `meiro/voice/<声>/<場面><番号>.mp3`（場面: start, cheer, bump, item, here, hint, goal）。PR #15 で公開。
- 迷路の大きさ: ★3×4、★★4×6、★★★6×8、★★★★8×11（横向きなら縦横入れかえ）。深さ優先で作り、スタートとゴールは反対の角。アイテムは正解の道の上。
- 指の動きを 0.2マスごとに区切って、となりの通れるマスへ1マスずつ進む（ななめに角をかすめたときは、かべのない曲がり方があればそちらを通る）。かべに当たったら その先はたどらない。キャラは通ったマスの中心を順にたどる（`hero.way`）。v0.1 は「3マス以内なら近道」にしていたため、かべ越しに飛べるバグがあった。
- 指の管理: 新しいタッチは前の指をいつでも上書き、`lostpointercapture`・画面切りかえでも指をはなした扱い。ゴール画面のタイマーは `clearTimer` で、ゲーム開始・ホームで取り消す。
- おまかせ: `omakase` フラグ。`randomTheme()` は直前のキャラ以外から選ぶ。キャラのボタンを押すと おまかせは解除。
- 保存: localStorage `meiro-book`（シール帳）、`meiro-guide`（みちしるべ）、`meiro-voice`（`ai:jf_alpha` 標準 / `dev` / `off`）。
- 声の作り方は まちがいさがし と同じ（Kokoro fp16 で候補を作り、whisper-tiny で聞き取って選ぶ）。56こ全部一致。道具は `/mnt/project-files/meiro/tools/`（cand.py, pick.py, asr.mjs）。
- 注意: システムの pip だと unidic-lite が入らない（setuptools の install_layout エラー）。setuptools を新しくした venv を使う。
