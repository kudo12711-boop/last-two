# ゆびで めいろ（幼児向け）

最終更新: 2026-11-23 ／ いまの版: v0.5（v0.4 まで公開済み、声の作りなおしは まだ公開していない）

## ひとことで

画面の迷路を指でなぞって、キャラクターをゴールまで連れていく幼児向けゲームです。かべにぶつかっても失敗にならず、やさしい声で応援してくれます。

## 遊ぶ場所

- 公開ページ: https://kudo12711-boop.github.io/last-two/meiro/ （ログインなしで誰でも遊べます。2026-10-25 公開）（英語: `?lang=en`）
- ファイル: `/mnt/project-files/meiro/index.html`、画面の画像 `/mnt/project-files/meiro/screenshot.png`

## 生まれたきっかけ

2026-10-25、くどうさん「幼児用のゲームで、画面に表示された迷路を指でなぞって解くというものを作りましょう」。

## 遊び方（いまの版）

- キャラを選ぶ（「🎲 おまかせ」を押すと、迷路ごとにキャラがランダムで決まる）: 🐶→🏠、🐰→🥕、🐧→🐟、🐝→🌻、🚀→🌙、🚗→🏁。
- キャラに指をあててなぞると、道にそってついてくる。かべは通りぬけられず、ぶつかると「ぽよん」とゆれるだけ。
- 指をはなしても、キャラかなぞった線のどこからでも続きができる。逆になぞれば戻れる。
- 道のとちゅうのアイテム（🦴や🍓）を集めてゴールすると、紙ふぶきとシール1まい。
- むずかしさ ★〜★★★★（2〜5さい向け）。迷路は毎回自動で作る。
- 「みちしるべ」（ゴールまでの道にうすい点、最初はオン）、💡 で道がピカピカ光る。
- 声は [まちがいさがし](machigai.md) と同じ AI の声（4種類×14セリフ。「ゴールまで なぞってね」「もうすこし！」「ゴール！やったね！」など）。
- 日本語 / English 切りかえ（タイトルの下のボタンか、せってい）。英語のときは 英語の AI の声。

## 技術メモ

- リポジトリ `meiro/index.html`（1ファイル）＋ `meiro/voice/<声>/<場面><番号>.mp3`（場面: start, cheer, bump, item, here, hint, goal）。PR #15 で公開。
- 迷路の大きさ: ★3×4、★★4×6、★★★6×8、★★★★8×11（横向きなら縦横入れかえ）。深さ優先で作り、スタートとゴールは反対の角。アイテムは正解の道の上。
- 指の動きを 0.2マスごとに区切って、となりの通れるマスへ1マスずつ進む（ななめに角をかすめたときは、かべのない曲がり方があればそちらを通る）。かべに当たったら その先はたどらない。キャラは通ったマスの中心を順にたどる（`hero.way`）。v0.1 は「3マス以内なら近道」にしていたため、かべ越しに飛べるバグがあった。
- 指の管理: 新しいタッチは前の指をいつでも上書き、`lostpointercapture`・画面切りかえでも指をはなした扱い。ゴール画面のタイマーは `clearTimer` で、ゲーム開始・ホームで取り消す。
- おまかせ: `omakase` フラグ。`randomTheme()` は直前のキャラ以外から選ぶ。キャラのボタンを押すと おまかせは解除。
- 保存: localStorage `meiro-book`（シール帳）、`meiro-guide`（みちしるべ）、`meiro-voice`（`ai:jf_alpha` 標準 / `dev` / `off`）。
- 声の作り方は まちがいさがし と同じ（Kokoro fp16 で候補を作り、whisper-tiny で聞き取って選ぶ）。56こ全部一致。道具は `/mnt/project-files/meiro/tools/`（cand.py, pick.py, asr.mjs）。
- 注意: システムの pip だと unidic-lite が入らない（setuptools の install_layout エラー）。setuptools を新しくした venv を使う。
- 課金: `<script src="../common/kakin.js">` を ゲームの script の前に読み、`Kakin.setup({game: 'meiro', ...})`。🔒は `.kk-lock` クラス、さわったら `Kakin.ask()`、ぜんぶ版かどうかは `Kakin.full()`。むりょうの範囲は `FREE_HEROES`（THEMES の はじめの2つ）。
- 英語（2026-11-11）: 言語は `?lang=ja|en` → 前回えらんだもの（localStorage `meiro-lang`）→ 入口ページで えらんだもの（`games-lang`）→ ブラウザの言語（日本語以外は英語）。文字は `TEXT`（ja / en）。声の設定は `ai:1`〜`ai:4`（AIのこえ 何番）で、日本語は jf_alpha / jf_gongitsune / jf_nezumi / jf_tebukuro、英語は af_heart / af_bella / bf_emma / am_michael の フォルダから読む（むかしの `ai:jf_alpha` も読める）。英語の声は `/mnt/project-files/i18n/tools/en_voice.py`（Kokoro-82M v1.0 onnx、espeak の英語読み）で作った。
- 声の順番待ち（2026-11-16）: 声はすべて `vqAdd()` の順番待ち（`VQ`）を通す。前の声を止めずに、終わったら次を鳴らす（AudioBuffer の `onended`、読み上げの `onend`、念のための時間切れ `max`）。`mode` なし＝待つ、`'idle'`＝ほかの声が鳴っていなければだけ（おしゃべり）、`'swap'`＝`'swap'` どうしだけ入れかわる（数を数える声・タップで名前）。`tag` で同じ種類の声が積み重ならないようにする（`vqHas()`）。止めるのは `hush()` だけ（画面を出るとき・音を消すとき・声のためし・録音の再生）。同じしくみは [ひらがな あそび](hiragana.md)・[ちいさな おうこく](oukoku.md) でも使っている。

- アプリの準備（2026-11-19）: `manifest.webmanifest`（アプリの名札）、`app/` の仮アイコン、`app-files.json`（アプリとして開いたときに まとめて保存するファイルの一覧）、`<head>` に `common/app.js`（オフライン）と `common/hikkoshi.js`（games.hajimaruyo.com への記録の引っ越し）。ファイルを足したり変えたりしたら `node tools/make_app.cjs --no-icons` で一覧を作りなおす。くわしくは [app-plan.md](app-plan.md)。

- 日本語の声（2026-11-23〜）: VOICEVOX。台本は `/mnt/project-files/voice-ja/build_lines.py`、作るのは `make_voicevox.py`。フォルダは `voice/vv_himari|vv_metan|vv_zunda|vv_hau/`（AIのこえ 1〜4。前の Kokoro の jf_* は消した）。きまり・クレジット・作り方は [voice-ja.md](voice-ja.md)。
