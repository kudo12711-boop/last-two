# 有料化とアプリ化の進め方

最終更新: 2026-11-19 ／ いまの段階: アカウントの要らない準備（名札・アイコン・オフライン・記録の引っ越し・説明文の下書き）ができた。ドメインの切りかえ待ち

## ひとことで

- 「ぜんぶ無料で出して、あとから有料にする」は、**ラスト・ツーだけ**に向いています。ほかのゲームは、**はじめから「ずっと無料の部分」と「お金を払う部分」を分けておく**ほうが合います（あとから🔒を付けると、無料で遊んでいた人に「取り上げられた」と感じさせるため）。
- お金をもらうのは **Google Play のアプリにしてから**がおすすめです。ブラウザ版は「無料で遊べるお試し」として残し、アプリへの入口にします。
- 子ども向けのゲームは、まず **1本のアプリにまとめて**出すのがおすすめです（登録・審査・テストが1回ですみ、👪 ファミリーパスとも相性がよい）。

## Google Play に出す方法（やさしい説明）

- **TWA（ティー・ダブリュー・エー）**: ブラウザのゲームを、そのまま Play のアプリの「包み」に入れる方法。ゲームを作り直さなくてよい。Android だけ（iPhone は別の方法が必要）。中身は ウェブから読みこむので、ゲームを直したら アプリを出し直さなくても 新しくなる。
- そのための準備（Claude ができること）: アプリの名札とアイコン、オフラインのしくみ、Play の支払いへのつなぎ（Digital Goods API という、TWA から Play の支払いを使うしくみ）、ストアの説明文とスクリーンショット（日本語・英語）、プライバシーポリシーの下書き。
- iPhone（App Store）は、包み方が違い（Capacitor など）、Apple は「ウェブをそのまま包んだだけ」のアプリに厳しいので、Android のあとに考える。

## お金の受け取り方: Play の支払い か ウェブの支払い か

**おすすめ: Play の支払い（Google Play 請求）**

- Play で配るアプリの中で 絵やステージ（デジタルのもの）を売るときは、基本は Play の支払いを使うきまり（日本では ほかの支払いも選べるようになってきたが、手続きが ふえる）。
- 手数料は 多くの場合 15%（480円なら 約72円）。カード情報の管理、月額パスの更新と解約、返金、機種変更のときの「購入の復元」を Google がやってくれる。
- ウェブの支払い（Stripe など）は 手数料が 3〜4% と安いが、①ログインのしくみ（買った人をおぼえるサーバー）②特定商取引法の表示（名前・住所・連絡先。請求があれば出す、の書き方もある）③問い合わせ・返金の対応、が自分の仕事になる。個人で始めるには重い。
- ブラウザ版で売るのは、アプリが軌道に乗ってから考えればよい。

## games.hajimaruyo.com への切りかえ

### アドレスが どう変わるか

- 今の `https://kudo12711-boop.github.io/last-two/〇〇/` が `https://games.hajimaruyo.com/〇〇/` になる（例: めいろ → games.hajimaruyo.com/meiro/、ラスト・ツー → games.hajimaruyo.com/）。
- **前のアドレスは自動で新しいアドレスへ とぶ**（GitHub が転送する。後ろの部分も そのまま）。LINE で送ったリンク、QR コード、ブックマーク、ホーム画面のアイコン、かくしURL（try-…）も そのまま使える。
- かくしURL は `games.hajimaruyo.com/try-…/` になる。検索よけ（noindex）は そのまま。
- ラスト・ツーの招待リンクは、開いているアドレスに合わせて自動で新しいアドレスになる（11/19 に直した）。

### 記録の引っ越し（くどうさん 11/19「引っ越してください」）

ブラウザは 記録を アドレスごとに分けて保存するので、そのままでは 新しいアドレスで 記録が見えなくなる。そこで `common/hikkoshi.js` を全ゲームに入れた（新しいアドレスのときだけ動く。前のアドレスでは何もしない）。

- 新しいアドレスで はじめて開くと、前のアドレスにある「おひっこしページ」へ一瞬とんで もどる。そのあいだに 進み具合・設定・コイン・シール・図鑑・旅などを うつす。
- 写真・録音（まちがいさがし・てんつなぎ・けずって・かくれんぼ・キャンピングカーの保存）が あれば、画面の上に「前のアドレスで とった 写真や 録音を うつしますか？ [うつす]」が出る。押すと 小さな窓が開いて うつす。
- うつせないもの: **Fire TV のキャンピングカーの旅**（テレビでは クッキーに保存しているため）。切りかえの前に、テレビの「📱 スマホで受けとる」か 引き継ぎコードで 移しておく。お知らせ（🔔）・カメラ・マイクの許可は、新しいアドレスで もう一度 たずねられる。

## 技術メモ

- アプリ用のファイルは `node tools/make_app.cjs` で作る（設定は `tools/apps.json`）。各ゲームに `manifest.webmanifest`、`app/icon-192.png`・`icon-512.png`・`icon-maskable-512.png`（仮。絵文字を色の板にのせたもの）、`app-files.json`、`<head>` の `<!-- app -->〜<!-- /app -->` と `<!-- hikkoshi -->`。アイコンを変えずに一覧だけ作りなおすときは `--no-icons`。ゲームのファイルを変えたら 作りなおす（`app-files.json` の version が変わり、アプリが まとめて取りなおす）。
- まとめアプリ用の名札は `games/manifest.webmanifest`（scope は `../` = サイト全体）。ラスト・ツーの名札は サイトの いちばん上（`/manifest.webmanifest`）。
- オフライン: `sw.js`（サイトの いちばん上、scope もサイト全体）。ページは ネット優先（直したら すぐ出る）、絵・声などは 保存したものを先に出して うしろで入れかえ。保存の名前は `?v=` を外したもの。よそのサイトは フォントと CDN だけ。`camper/` は さわらない（camper は自分の `camper/sw.js`）。ふつうのブラウザでは 一度開いたものだけ保存し、アプリとして開いたとき（display-mode standalone など、または `?app=1`）だけ `app-files.json` を まとめて保存する。
- 記録の引っ越し: `common/hikkoshi.js` は `<meta charset>` のすぐ後（ゲームのプログラムより前）。`*.hajimaruyo.com` のときだけ動く。`asobi-hikkoshi`（localStorage）= `done` か `idb`。`ok.txt` を先に読んで おひっこしページが あるときだけ とぶ（GitHub Pages は `Access-Control-Allow-Origin: *` を返すので読める）。もどりの `#hk=` は、この窓から とんだとき（sessionStorage `hk-tried`）だけ受けつける。写真・録音は `window.open` の小窓から `postMessage`（相手のアドレスを確かめる）。おひっこしページは `*.hajimaruyo.com` と localhost にしか記録を わたさない。試しは localhost で `?hk-test=<おひっこしページのURL>`。アプリとして開いたときは とばない。しばらくして（例: 2027年春）みんなが うつしたころに 外す。


- TWA は Bubblewrap（Google の道具）で作れる。GitHub Pages は Jekyll で `.` で始まるフォルダを出さないので、`.well-known/assetlinks.json` を置くときは `_config.yml` に `include: [".well-known"]` を足す（または `.nojekyll`。ただし docs の .md の見え方が変わる）。サイトとアプリを結びつける `/.well-known/assetlinks.json` が サイトの いちばん上に要るが、いまの GitHub Pages は `kudo12711-boop.github.io/last-two/` という「下の階」なので置けない。**屋号のドメインを GitHub Pages につなぐ（カスタムドメイン）と解決する**（`kudo12711-boop.github.io` という名前のリポジトリを別に作って置く手もあるが、アドレスが github.io のままになる）。これも屋号のドメインを先に決める理由。
- TWA から Play の支払い: Digital Goods API ＋ Payment Request API。`Kakin.provider = {buy, restore}` をこれで実装する。月額パスは Play の定期購入にする。
- オフライン: ゲームごとに service worker を足し、声や絵のファイル（てんつなぎ 約12MB、ひらがな 約11MB など）を最初に読みこんでおく。まとめアプリでは ゲームを開いたときに そのゲームの分だけ保存する。
- 子ども向けアプリは Play の「ファミリー向け」のきまり（広告の制限、個人情報の扱い、外へのリンクの制限）を守る。いまの子ども向けゲームは 広告なし・外へのリンクほぼなし・写真は端末の中だけ なので 合っている。
