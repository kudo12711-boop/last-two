## v0.1 の中身

ホームに大きなボタンが3つ。はじめて遊ぶときは「あみだくじって？」の説明（いぬが ゆっくり たどって、声で ルールを言う）が自動で出る。ホームの「❓ あみだくじって？」でいつでも見られる。

1. **🦴 ごはんを とどけて**（考える遊び）
   - 上に どうぶつ、下に その どうぶつの ごはん（🐶🦴・🐱🐟・🐰🥕・🐵🍌・🐻🍯・🐭🧀）。ごはんの ならびは ばらばら。
   - せんの あいだを タッチすると はし（よこの せん）が かかる。もう一度 タッチで とれる。となりあう はしは つながらないので、新しい はしを かけると となりの はしは 自動で外れる。
   - 「いってみよう！」で どうぶつが 1ぴきずつ たどる（色つきの あとが のこる）。ぜんいん じぶんの ごはんに ついたら クリア。ちがったら「あれれ？」→ はしを なおして もう一度。
   - 「💡 ヒント」: かけるとよい はし（緑）か、とるとよい はし（赤）を 光らせて、声で教える。
   - 12ステージ: 2本 → 3本 → 4本 → 5本。ステージ2から「木の はし」（動かせない、最初から ある はし）が出て、それを打ち消すように考える。13こめに「∞ どんどん」（4〜5本、毎回あたらしい問題）。
2. **👀 どれに つくかな？**（先を よむ遊び）
   - あみだが できあがっていて、光っている どうぶつが どこに つくか、下の ものを タッチして あてる。タッチすると どうぶつが たどって こたえあわせ。5もんで ⭐ いくつ。
   - やさしい（3本）／むずかしい（4〜5本）。いちばん よかった点を おぼえる。
3. **🎁 みんなで くじびき**（家族で ほんとうに つかう）
   - 2〜5人。きめること: じゅんばん（1ばん〜）・あたり（1人だけ ⭐）・おやつ・おてつだい・じぶんで かく（下の ことばを 入力）。
   - あみだは 紙で かくれていて、みんなで すきな ところに はしを たせる（ほんものの あみだくじと同じ）。「あける！」で 紙が めくれ、どうぶつを タッチすると 1ぴきずつ すすむ（「みんな すすむ」も ある）。ついた ところの カードが めくれる。

### 声

- AI の声（日本語4・英語4）と この端末の声、声なし。「おうちのかた」で えらぶ。
- 声は「順番待ち」（ひらがな あそび・ちいさな おうこく と同じ）。前の声を とちゅうで 止めない。止めるのは「もどる」と アプリを閉じたときだけ。「どれに つくかな？」は ほめる声が おわってから 次の もんだいを 読む。

## 技術メモ

- ファイル: `try-b0e17c086f1b01da/index.html`（1ファイル、canvas に描く）＋ `voice/<声>/<key>.mp3`。`../common/kakin.js` を読む。コピーは `/mnt/project-files/amida/`。
- あみだの持ち方: `L.G[r][i]` = 段 r で せん i と i+1 の あいだの はし（0 なし／1 木の はし／2 子どもの はし／3 くじびきの かくれた はし／4 くじびきで たした はし）。同じ段で となりあう はしは 置けない（`canPut`）。`trace(G,start)` で どこに つくか、`ends(G)` で ぜんいんの行き先。
- ステージ: `STAGES` = [せんの数, 答えの はしの数, 木の はしの数]。`genBuild` が 木の はし → 答えの はし をランダムに置いて、下の ごはんの ならびを 決める（答えの はしは 消して 子どもに 考えさせる）。木の はしだけで とけてしまう問題は やりなおす。
- ヒント: 子どもの はしが 答えの一部なら、足りない はしを 見せる。ちがう道を 作っているときは、1本 たす／とる の中で いちばん ゴールに近づくもの（行き先のずれの合計が へるもの）を 見せる。
- 記録: localStorage `amida-v1`（lang, voice, snd, cleared＝クリアしたステージ数, best＝どれに つくかな の最高点, seen＝説明を見たか, lot＝くじびきの設定と じぶんで かいた ことば）。
- テスト用: `?test=1` で `window.__amida` が使える（自動テストで答えを入れるため）。
- 声の作り方: index.html の `//@@LINES-BEGIN`〜`END` を node で JSON にして（`/mnt/project-files/amida/tools/lines.json`）、`/mnt/project-files/amida/tools/make_voice.py` で作る（Kokoro-82M v1.0 onnx。モデルは github.com/thewh1teagle/kokoro-onnx の releases、venv に `kokoro-onnx lameenc misaki fugashi unidic-lite`）。日本語は 助詞の「は」を わ に直す（「はし」は そのまま）。
- アプリの準備: `tools/apps.json` に 追加済み。ファイルを変えたら `node tools/make_app.cjs --no-icons` で `app-files.json` を作りなおす。
